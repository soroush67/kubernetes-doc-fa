نصب و راه‌اندازی kubectl در ویندوز

پیش از شروع

باید از نسخه‌ای از kubectl استفاده کنید که حداکثر یک نسخهٔ فرعی (minor) با کلاستر شما اختلاف داشته باشد. برای نمونه، کلاینت v1.37 می‌تواند با control plane نسخه‌های v1.36، v1.37 و v1.38 ارتباط برقرار کند. استفاده از جدیدترین نسخهٔ سازگار kubectl به جلوگیری از مشکلات پیش‌بینی‌نشده کمک می‌کند.

نصب kubectl در ویندوز

برای نصب kubectl در ویندوز روش‌های زیر وجود دارد:

  • نصب فایل باینری kubectl در ویندوز (با دانلود مستقیم یا curl)
  • نصب در ویندوز با Chocolatey، Scoop یا winget

نصب فایل باینری kubectl در ویندوز (با دانلود مستقیم یا curl)

  1. برای نصب kubectl روی دستگاه ویندوزی خود دو گزینه دارید:

    • دانلود مستقیم:

      با مراجعه به صفحهٔ انتشارهای کوبرنتیز، فایل باینری جدیدترین انتشار وصله‌ای (patch) نسخهٔ 1.37 را مستقیماً برای معماری مورد نظر خود دانلود کنید. حتماً فایل باینری متناسب با معماری خود (مانند amd64، arm64 و غیره) را انتخاب کنید.

    • با استفاده از curl:

      اگر curl را نصب کرده‌اید، از این دستور استفاده کنید:

      curl.exe -LO "https://dl.k8s.io/release/v1.37.0/bin/windows/amd64/kubectl.exe"
توجه:

برای یافتن جدیدترین نسخهٔ پایدار (برای نمونه، جهت استفاده در اسکریپت‌ها)، به https://dl.k8s.io/release/stable.txt مراجعه کنید.

  1. اعتبارسنجی فایل باینری (اختیاری)

    فایل checksum مربوط به kubectl را دانلود کنید:

    curl.exe -LO "https://dl.k8s.io/v1.37.0/bin/windows/amd64/kubectl.exe.sha256"

    فایل باینری kubectl را با فایل checksum اعتبارسنجی کنید:

    • با استفاده از Command Prompt و مقایسهٔ دستی خروجی CertUtil با فایل checksum دانلودشده:

      CertUtil -hashfile kubectl.exe SHA256
type kubectl.exe.sha256

    • با استفاده از PowerShell و خودکارسازی بررسی با عملگر -eq برای دریافت نتیجهٔ True یا False:

       $(Get-FileHash -Algorithm SHA256 .\kubectl.exe).Hash -eq $(Get-Content .\kubectl.exe.sha256)

  2. پوشهٔ فایل باینری kubectl را به انتها یا ابتدای متغیر محیطی PATH خود اضافه کنید.

  3. آزمایش کنید تا مطمئن شوید نسخهٔ kubectl با نسخهٔ دانلودشده یکسان است:

    kubectl version --client

    یا برای مشاهدهٔ جزئیات نسخه از این دستور استفاده کنید:

    kubectl version --client --output=yaml
توجه:

Docker Desktop برای ویندوز نسخهٔ مخصوص خود از kubectl را به PATH اضافه می‌کند. اگر پیش‌تر Docker Desktop را نصب کرده‌اید، ممکن است لازم باشد مدخل PATH خود را پیش از مدخلی قرار دهید که نصب‌کنندهٔ Docker Desktop اضافه کرده است، یا kubectl مربوط به Docker Desktop را حذف کنید.

نصب در ویندوز با Chocolatey، Scoop یا winget {#install-nonstandard-package-tools}

  1. برای نصب kubectl در ویندوز می‌توانید از مدیر بستهٔ Chocolatey، نصب‌کنندهٔ خط فرمان Scoop یا مدیر بستهٔ winget استفاده کنید.
choco
choco install kubernetes-cli
scoop
scoop install kubectl
winget
winget install -e --id Kubernetes.kubectl

  1. آزمایش کنید تا مطمئن شوید نسخهٔ نصب‌شده به‌روز است:

    kubectl version --client

  2. به پوشهٔ خانگی (home) خود بروید:

    # If you're using cmd.exe, run: cd %USERPROFILE%
cd ~

  3. پوشهٔ .kube را ایجاد کنید:

    mkdir .kube

  4. به پوشهٔ .kube که هم‌اکنون ایجاد کردید بروید:

    cd .kube

  5. kubectl را برای استفاده از یک کلاستر کوبرنتیز راه دور پیکربندی کنید:

    New-Item config -type file
توجه:

فایل config را با یک ویرایشگر متن دلخواه، مانند Notepad، ویرایش کنید.

بررسی پیکربندی kubectl

پیکربندی‌ها و افزونه‌های اختیاری kubectl

فعال‌سازی تکمیل خودکار در پوسته

ابزار kubectl از تکمیل خودکار (autocompletion) برای Bash، Zsh، Fish و PowerShell پشتیبانی می‌کند که می‌تواند بخش زیادی از تایپ کردن را برای شما کاهش دهد.

در ادامه، مراحل راه‌اندازی تکمیل خودکار برای PowerShell آمده است.

پیکربندی kuberc

برای اطلاعات بیشتر، kuberc را ببینید.

نصب افزونهٔ kubectl convert

  1. جدیدترین انتشار را با این دستور دانلود کنید:

    curl.exe -LO "https://dl.k8s.io/release/v1.37.0/bin/windows/amd64/kubectl-convert.exe"

  2. فایل باینری را اعتبارسنجی کنید (اختیاری).

    فایل checksum مربوط به kubectl-convert را دانلود کنید:

    curl.exe -LO "https://dl.k8s.io/v1.37.0/bin/windows/amd64/kubectl-convert.exe.sha256"

    فایل باینری kubectl-convert را با فایل checksum اعتبارسنجی کنید:

    • با استفاده از Command Prompt و مقایسهٔ دستی خروجی CertUtil با فایل checksum دانلودشده:

      CertUtil -hashfile kubectl-convert.exe SHA256
type kubectl-convert.exe.sha256

    • با استفاده از PowerShell و خودکارسازی بررسی با عملگر -eq برای دریافت نتیجهٔ True یا False:

      $($(CertUtil -hashfile .\kubectl-convert.exe SHA256)[1] -replace " ", "") -eq $(type .\kubectl-convert.exe.sha256)

  3. پوشهٔ فایل باینری kubectl-convert را به انتها یا ابتدای متغیر محیطی PATH خود اضافه کنید.

  4. بررسی کنید که افزونه با موفقیت نصب شده باشد.

    kubectl convert --help

    اگر خطایی مشاهده نکردید، یعنی افزونه با موفقیت نصب شده است.

  5. پس از نصب افزونه، فایل‌های نصب را پاک کنید:

    del kubectl-convert.exe
del kubectl-convert.exe.sha256
