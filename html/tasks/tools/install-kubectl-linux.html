نصب و راه‌اندازی kubectl روی لینوکس

پیش از شروع

نسخهٔ kubectl شما باید حداکثر یک نسخهٔ فرعی (minor) با نسخهٔ کلاستر اختلاف داشته باشد. برای مثال، یک کلاینت v1.37 می‌تواند با control plane نسخه‌های v1.36، v1.37 و v1.38 ارتباط برقرار کند. استفاده از جدیدترین نسخهٔ سازگار kubectl از بروز مشکلات پیش‌بینی‌نشده جلوگیری می‌کند.

نصب kubectl روی لینوکس

برای نصب kubectl روی لینوکس، روش‌های زیر وجود دارد:

  • نصب فایل اجرایی kubectl با curl روی لینوکس
  • نصب با مدیر بستهٔ بومی سیستم‌عامل
  • نصب با سایر مدیران بسته

نصب فایل اجرایی kubectl با curl روی لینوکس

  1. آخرین نسخهٔ منتشرشده را با دستور زیر دانلود کنید:
x86-64

curl -LO "https://dl.k8s.io/release/$(curl -L -s https://dl.k8s.io/release/stable.txt)/bin/linux/amd64/kubectl"

ARM64

curl -LO "https://dl.k8s.io/release/$(curl -L -s https://dl.k8s.io/release/stable.txt)/bin/linux/arm64/kubectl"

توجه:

برای دانلود یک نسخهٔ مشخص، بخش $(curl -L -s https://dl.k8s.io/release/stable.txt) را در دستور با شمارهٔ نسخهٔ موردنظر جایگزین کنید.

برای مثال، برای دانلود نسخهٔ 1.37.0 روی لینوکس x86-64، دستور زیر را وارد کنید:

curl -LO https://dl.k8s.io/release/v1.37.0/bin/linux/amd64/kubectl

و برای لینوکس ARM64، دستور زیر را وارد کنید:

curl -LO https://dl.k8s.io/release/v1.37.0/bin/linux/arm64/kubectl

  1. اعتبارسنجی فایل اجرایی (اختیاری)

    فایل checksum مربوط به kubectl را دانلود کنید:

x86-64

curl -LO "https://dl.k8s.io/release/$(curl -L -s https://dl.k8s.io/release/stable.txt)/bin/linux/amd64/kubectl.sha256"

ARM64

curl -LO "https://dl.k8s.io/release/$(curl -L -s https://dl.k8s.io/release/stable.txt)/bin/linux/arm64/kubectl.sha256"

فایل اجرایی kubectl را با فایل checksum اعتبارسنجی کنید:

echo "$(cat kubectl.sha256)  kubectl" | sha256sum --check

اگر فایل معتبر باشد، خروجی به این صورت است:

kubectl: OK

اگر بررسی ناموفق باشد، دستور sha256 با وضعیت غیرصفر خاتمه می‌یابد و خروجی‌ای مشابه زیر چاپ می‌کند:

kubectl: FAILED
sha256sum: WARNING: 1 computed checksum did NOT match
توجه:

فایل اجرایی و فایل checksum را از یک نسخه دانلود کنید.

  1. نصب kubectl

    sudo install -o root -g root -m 0755 kubectl /usr/local/bin/kubectl
توجه:

اگر روی سیستم مقصد دسترسی root ندارید، همچنان می‌توانید kubectl را در پوشهٔ ~/.local/bin نصب کنید:

chmod +x kubectl
mkdir -p ~/.local/bin
mv ./kubectl ~/.local/bin/kubectl
# and then append (or prepend) ~/.local/bin to $PATH

  1. بررسی کنید که نسخهٔ نصب‌شده به‌روز باشد:

    kubectl version --client

    یا برای مشاهدهٔ جزئیات نسخه از این دستور استفاده کنید:

    kubectl version --client --output=yaml

نصب با مدیر بستهٔ بومی سیستم‌عامل

توزیع‌های مبتنی بر Debian

  1. فهرست بسته‌های apt را به‌روزرسانی کنید و بسته‌های لازم برای استفاده از مخزن apt کوبرنتیز را نصب کنید:

    sudo apt-get update
# apt-transport-https may be a dummy package; if so, you can skip that package
sudo apt-get install -y apt-transport-https ca-certificates curl gnupg

  2. کلید عمومی امضای مخازن بستهٔ کوبرنتیز را دانلود کنید. همهٔ مخازن از یک کلید امضای یکسان استفاده می‌کنند؛ بنابراین می‌توانید نسخهٔ درج‌شده در URL را نادیده بگیرید:

    # If the folder `/etc/apt/keyrings` does not exist, it should be created before the curl command, read the note below.
# sudo mkdir -p -m 755 /etc/apt/keyrings
curl -fsSL https://pkgs.k8s.io/core:/stable:/v1.37/deb/Release.key | sudo gpg --dearmor -o /etc/apt/keyrings/kubernetes-apt-keyring.gpg
sudo chmod 644 /etc/apt/keyrings/kubernetes-apt-keyring.gpg # allow unprivileged APT programs to read this keyring
توجه:

در نسخه‌های قدیمی‌تر از Debian 12 و Ubuntu 22.04، پوشهٔ /etc/apt/keyrings به‌طور پیش‌فرض وجود ندارد و باید پیش از اجرای دستور curl ساخته شود.

  1. مخزن apt مناسب کوبرنتیز را اضافه کنید. اگر می‌خواهید از نسخه‌ای از کوبرنتیز غیر از v1.37 استفاده کنید، در دستور زیر v1.37 را با نسخهٔ فرعی موردنظر جایگزین کنید:

    # This overwrites any existing configuration in /etc/apt/sources.list.d/kubernetes.list
echo 'deb [signed-by=/etc/apt/keyrings/kubernetes-apt-keyring.gpg] https://pkgs.k8s.io/core:/stable:/v1.37/deb/ /' | sudo tee /etc/apt/sources.list.d/kubernetes.list
sudo chmod 644 /etc/apt/sources.list.d/kubernetes.list   # helps tools such as command-not-found to work correctly
توجه:

برای ارتقای kubectl به یک نسخهٔ فرعی دیگر، باید پیش از اجرای apt-get update و apt-get upgrade، نسخهٔ درج‌شده در /etc/apt/sources.list.d/kubernetes.list را تغییر دهید. این فرایند در تغییر مخزن بستهٔ کوبرنتیز با جزئیات بیشتری شرح داده شده است.

  1. فهرست بسته‌های apt را به‌روزرسانی کنید و سپس kubectl را نصب کنید:

    sudo apt-get update
sudo apt-get install -y kubectl
توزیع‌های مبتنی بر Red Hat

  1. مخزن yum کوبرنتیز را اضافه کنید. اگر می‌خواهید از نسخه‌ای از کوبرنتیز غیر از v1.37 استفاده کنید، در دستور زیر v1.37 را با نسخهٔ فرعی موردنظر جایگزین کنید.

    # This overwrites any existing configuration in /etc/yum.repos.d/kubernetes.repo
cat <<EOF | sudo tee /etc/yum.repos.d/kubernetes.repo
[kubernetes]
name=Kubernetes
baseurl=https://pkgs.k8s.io/core:/stable:/v1.37/rpm/
enabled=1
gpgcheck=1
gpgkey=https://pkgs.k8s.io/core:/stable:/v1.37/rpm/repodata/repomd.xml.key
EOF
توجه:

برای ارتقای kubectl به یک نسخهٔ فرعی دیگر، باید پیش از اجرای dnf update، نسخهٔ درج‌شده در /etc/yum.repos.d/kubernetes.repo را تغییر دهید. این فرایند در تغییر مخزن بستهٔ کوبرنتیز با جزئیات بیشتری شرح داده شده است.

  1. ابزار kubectl را با dnf نصب کنید:

    sudo dnf install -y kubectl

نصب با سایر مدیران بسته

Snap

اگر از Ubuntu یا توزیع لینوکس دیگری استفاده می‌کنید که از مدیر بستهٔ snap پشتیبانی می‌کند، kubectl به‌صورت یک برنامهٔ snap در دسترس است.

snap install kubectl --classic
kubectl version --client
Homebrew

اگر روی لینوکس از مدیر بستهٔ Homebrew استفاده می‌کنید، kubectl از این طریق قابل نصب است.

brew install kubectl
kubectl version --client

نصب افزونهٔ kubectl convert

  1. آخرین نسخهٔ منتشرشده را با دستور زیر دانلود کنید:
x86-64

curl -LO "https://dl.k8s.io/release/$(curl -L -s https://dl.k8s.io/release/stable.txt)/bin/linux/amd64/kubectl-convert"

ARM64

curl -LO "https://dl.k8s.io/release/$(curl -L -s https://dl.k8s.io/release/stable.txt)/bin/linux/arm64/kubectl-convert"

  1. اعتبارسنجی فایل اجرایی (اختیاری)

    فایل checksum مربوط به kubectl-convert را دانلود کنید:

x86-64

curl -LO "https://dl.k8s.io/release/$(curl -L -s https://dl.k8s.io/release/stable.txt)/bin/linux/amd64/kubectl-convert.sha256"

ARM64

curl -LO "https://dl.k8s.io/release/$(curl -L -s https://dl.k8s.io/release/stable.txt)/bin/linux/arm64/kubectl-convert.sha256"

فایل اجرایی kubectl-convert را با فایل checksum اعتبارسنجی کنید:

echo "$(cat kubectl-convert.sha256) kubectl-convert" | sha256sum --check

اگر فایل معتبر باشد، خروجی به این صورت است:

kubectl-convert: OK

اگر بررسی ناموفق باشد، دستور sha256 با وضعیت غیرصفر خاتمه می‌یابد و خروجی‌ای مشابه زیر چاپ می‌کند:

kubectl-convert: FAILED
sha256sum: WARNING: 1 computed checksum did NOT match
توجه:

فایل اجرایی و فایل checksum را از یک نسخه دانلود کنید.

  1. نصب kubectl-convert

    sudo install -o root -g root -m 0755 kubectl-convert /usr/local/bin/kubectl-convert

  2. بررسی کنید که افزونه با موفقیت نصب شده باشد

    kubectl convert --help

    اگر خطایی مشاهده نکردید، یعنی افزونه با موفقیت نصب شده است.

  3. پس از نصب افزونه، فایل‌های نصب را پاک کنید:

    rm kubectl-convert kubectl-convert.sha256
