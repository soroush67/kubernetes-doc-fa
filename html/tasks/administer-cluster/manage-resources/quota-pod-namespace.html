پیکربندی سهمیهٔ Pod برای یک فضای نام

محدود کردن تعداد Podهایی که می‌توانید در یک فضای نام ایجاد کنید.

این صفحه نشان می‌دهد که چگونه می‌توان برای تعداد کل Podهایی که در یک فضای نام اجرا می‌شوند سهمیه (quota) تعیین کرد. سهمیه‌ها را در یک آبجکت ResourceQuota مشخص می‌کنید.

پیش از شروع

باید یک کلاستر کوبرنتیز داشته باشید و ابزار خط فرمان kubectl باید برای ارتباط با کلاستر شما پیکربندی شده باشد. توصیه می‌شود این آموزش را روی کلاستری اجرا کنید که دست‌کم دو نود داشته باشد که نقش میزبان control plane را ندارند. اگر هنوز کلاستری ندارید، می‌توانید با استفاده از minikube یکی بسازید یا از یکی از این محیط‌های آزمایشی کوبرنتیز استفاده کنید:

  • iximiuz Labs
  • Killercoda
  • KodeKloud

باید در کلاستر خود دسترسی لازم برای ایجاد فضای نام را داشته باشید.

ایجاد یک فضای نام

یک فضای نام ایجاد کنید تا منابعی که در این تمرین می‌سازید از بقیهٔ کلاستر جدا بمانند.

kubectl create namespace quota-pod-example

ایجاد یک ResourceQuota

در ادامه نمونه‌ای از مانیفست یک ResourceQuota آمده است:

admin/resource/quota-pod.yaml
apiVersion: v1
kind: ResourceQuota
metadata:
  name: pod-demo
spec:
  hard:
    pods: "2"

آبجکت ResourceQuota را ایجاد کنید:

kubectl apply -f https://k8s.io/examples/admin/resource/quota-pod.yaml --namespace=quota-pod-example

اطلاعات جزئی ResourceQuota را مشاهده کنید:

kubectl get resourcequota pod-demo --namespace=quota-pod-example --output=yaml

خروجی نشان می‌دهد که سهمیهٔ این فضای نام دو Pod است و در حال حاضر هیچ Podای وجود ندارد؛ یعنی هیچ بخشی از سهمیه مصرف نشده است.

spec:
  hard:
    pods: "2"
status:
  hard:
    pods: "2"
  used:
    pods: "0"

در ادامه نمونه‌ای از مانیفست یک deployment آمده است:

admin/resource/quota-pod-deployment.yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: pod-quota-demo
spec:
  selector:
    matchLabels:
      purpose: quota-demo
  replicas: 3
  template:
    metadata:
      labels:
        purpose: quota-demo
    spec:
      containers:
      - name: pod-quota-demo
        image: nginx

در این مانیفست، replicas: 3 به کوبرنتیز می‌گوید که برای ایجاد سه Pod جدید تلاش کند که همگی یک برنامهٔ یکسان را اجرا می‌کنند.

آبجکت Deployment را ایجاد کنید:

kubectl apply -f https://k8s.io/examples/admin/resource/quota-pod-deployment.yaml --namespace=quota-pod-example

اطلاعات جزئی Deployment را مشاهده کنید:

kubectl get deployment pod-quota-demo --namespace=quota-pod-example --output=yaml

خروجی نشان می‌دهد که با وجود اینکه Deployment سه رونوشت (replica) تعیین کرده است، به دلیل سهمیه‌ای که پیش‌تر تعریف کردید، تنها دو Pod ایجاد شده‌اند:

spec:
  ...
  replicas: 3
...
status:
  availableReplicas: 2
...
lastUpdateTime: 2021-04-02T20:57:05Z
    message: 'unable to create pods: pods "pod-quota-demo-1650323038-" is forbidden:
      exceeded quota: pod-demo, requested: pods=1, used: pods=2, limited: pods=2'

انتخاب منبع

در این تمرین یک ResourceQuota تعریف کردید که تعداد کل Podها را محدود می‌کرد، اما می‌توانید تعداد کل انواع دیگر آبجکت‌ها را نیز محدود کنید. برای مثال، ممکن است تصمیم بگیرید تعداد CronJobهایی را که می‌توانند در یک فضای نام وجود داشته باشند محدود کنید.

پاک‌سازی

فضای نام خود را حذف کنید:

kubectl delete namespace quota-pod-example

گام‌های بعدی

برای مدیران کلاستر

  • پیکربندی درخواست‌ها و محدودیت‌های پیش‌فرض حافظه برای یک فضای نام

  • پیکربندی درخواست‌ها و محدودیت‌های پیش‌فرض CPU برای یک فضای نام

  • پیکربندی محدودیت‌های حداقل و حداکثر حافظه برای یک فضای نام

  • پیکربندی محدودیت‌های حداقل و حداکثر CPU برای یک فضای نام

  • پیکربندی سهمیه‌های حافظه و CPU برای یک فضای نام

  • پیکربندی سهمیه برای آبجکت‌های API

برای توسعه‌دهندگان برنامه

  • تخصیص منابع حافظه به کانتینرها و Podها

  • تخصیص منابع CPU به کانتینرها و Podها

  • تخصیص منابع CPU و حافظه در سطح Pod

  • پیکربندی کیفیت سرویس (Quality of Service) برای Podها
