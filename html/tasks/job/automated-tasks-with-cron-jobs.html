اجرای وظایف خودکار با CronJob

این صفحه نشان می‌دهد که چگونه می‌توان با استفاده از آبجکت CronJob در کوبرنتیز، وظایف خودکار را اجرا کرد.

پیش از شروع

باید یک کلاستر کوبرنتیز داشته باشید و ابزار خط فرمان kubectl باید برای ارتباط با کلاستر شما پیکربندی شده باشد. توصیه می‌شود این آموزش را روی کلاستری اجرا کنید که دست‌کم دو نود داشته باشد که نقش میزبان control plane را ندارند. اگر هنوز کلاستری ندارید، می‌توانید با استفاده از minikube یکی بسازید یا از یکی از این محیط‌های آزمایشی کوبرنتیز استفاده کنید:

  • iximiuz Labs
  • Killercoda
  • KodeKloud

ایجاد یک CronJob {#creating-a-cron-job}

هر کرون‌جاب (cron job) به یک فایل پیکربندی نیاز دارد. در ادامه، مانیفست یک CronJob آمده است که هر دقیقه یک وظیفهٔ نمایشی ساده را اجرا می‌کند:

application/job/cronjob.yaml
apiVersion: batch/v1
kind: CronJob
metadata:
  name: hello
spec:
  schedule: "* * * * *"
  jobTemplate:
    spec:
      template:
        spec:
          containers:
          - name: hello
            image: busybox:1.28
            imagePullPolicy: IfNotPresent
            command:
            - /bin/sh
            - -c
            - date; echo Hello from the Kubernetes cluster
          restartPolicy: OnFailure

با این دستور، CronJob نمونه را اجرا کنید:

kubectl create -f https://k8s.io/examples/application/job/cronjob.yaml

خروجی مشابه زیر است:

cronjob.batch/hello created

پس از ایجاد کرون‌جاب، وضعیت آن را با این دستور دریافت کنید:

kubectl get cronjob hello

خروجی مشابه زیر است:

NAME    SCHEDULE      SUSPEND   ACTIVE   LAST SCHEDULE   AGE
hello   */1 * * * *   False     0        <none>          10s

همان‌طور که از نتیجهٔ دستور پیداست، کرون‌جاب هنوز هیچ جابی (job) را زمان‌بندی یا اجرا نکرده است. حدود یک دقیقه ایجاد شدن جاب را زیر نظر بگیرید:

kubectl get jobs --watch

خروجی مشابه زیر است:

NAME               COMPLETIONS   DURATION   AGE
hello-4111706356   0/1                      0s
hello-4111706356   0/1           0s         0s
hello-4111706356   1/1           5s         5s

اکنون یک جاب در حال اجرا را دیدید که کرون‌جاب «hello» آن را زمان‌بندی کرده است. می‌توانید پایش جاب را متوقف کنید و دوباره کرون‌جاب را مشاهده کنید تا ببینید که جاب را زمان‌بندی کرده است:

kubectl get cronjob hello

خروجی مشابه زیر است:

NAME    SCHEDULE      SUSPEND   ACTIVE   LAST SCHEDULE   AGE
hello   */1 * * * *   False     0        50s             75s

باید ببینید که کرون‌جاب hello در زمانی که در ستون LAST SCHEDULE مشخص شده است، یک جاب را با موفقیت زمان‌بندی کرده است. در حال حاضر ۰ جاب فعال وجود دارد؛ یعنی جاب یا به پایان رسیده یا با شکست مواجه شده است.

اکنون پادهایی را که آخرین جاب زمان‌بندی‌شده ایجاد کرده است پیدا کنید و خروجی استاندارد یکی از آن‌ها را مشاهده کنید.

توجه:

نام جاب با نام پاد متفاوت است.

# Replace "hello-4111706356" with the job name in your system
pods=$(kubectl get pods --selector=job-name=hello-4111706356 --output=jsonpath={.items[*].metadata.name})

لاگ پاد را نمایش دهید:

kubectl logs $pods

خروجی مشابه زیر است:

Fri Feb 22 11:02:09 UTC 2019
Hello from the Kubernetes cluster

حذف یک CronJob {#deleting-a-cron-job}

هر زمان که دیگر به یک کرون‌جاب نیاز نداشتید، آن را با kubectl delete cronjob <cronjob name> حذف کنید:

kubectl delete cronjob hello

حذف کرون‌جاب، همهٔ جاب‌ها و پادهایی را که ایجاد کرده است پاک می‌کند و مانع از ایجاد جاب‌های بیشتر توسط آن می‌شود. برای آشنایی بیشتر با حذف جاب‌ها، بخش جمع‌آوری زباله را بخوانید.
