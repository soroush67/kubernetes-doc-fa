استفاده از Service برای دسترسی به یک برنامه در کلاستر

این صفحه نشان می‌دهد چگونه یک آبجکت Service در کوبرنتیز ایجاد کنید که کلاینت‌های خارجی بتوانند با آن به برنامه‌ای که در یک کلاستر اجرا می‌شود دسترسی پیدا کنند. این Service برای برنامه‌ای که دو نمونهٔ در حال اجرا دارد، توزیع بار (load balancing) فراهم می‌کند.

پیش از شروع

باید یک کلاستر کوبرنتیز داشته باشید و ابزار خط فرمان kubectl باید برای ارتباط با کلاستر شما پیکربندی شده باشد. توصیه می‌شود این آموزش را روی کلاستری اجرا کنید که دست‌کم دو نود داشته باشد که نقش میزبان control plane را ندارند. اگر هنوز کلاستری ندارید، می‌توانید با استفاده از minikube یکی بسازید یا از یکی از این محیط‌های آزمایشی کوبرنتیز استفاده کنید:

  • iximiuz Labs
  • Killercoda
  • KodeKloud

اهداف

  • دو نمونه از یک برنامهٔ Hello World را اجرا کنید.
  • یک آبجکت Service ایجاد کنید که یک پورت نود (node port) را در دسترس قرار دهد.
  • با استفاده از آبجکت Service به برنامهٔ در حال اجرا دسترسی پیدا کنید.

ایجاد یک Service برای برنامه‌ای که در دو پاد اجرا می‌شود

فایل پیکربندی Deployment برنامه در ادامه آمده است:

service/access/hello-application.yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: hello-world
spec:
  selector:
    matchLabels:
      run: load-balancer-example
  replicas: 2
  template:
    metadata:
      labels:
        run: load-balancer-example
    spec:
      containers:
        - name: hello-world
          image: us-docker.pkg.dev/google-samples/containers/gke/hello-app:2.0
          ports:
            - containerPort: 8080
              protocol: TCP

  1. یک برنامهٔ Hello World را در کلاستر خود اجرا کنید: با استفاده از فایل بالا، Deployment برنامه را ایجاد کنید:

    kubectl apply -f https://k8s.io/examples/service/access/hello-application.yaml

    دستور بالا یک Deployment و یک ReplicaSet مرتبط با آن ایجاد می‌کند. این ReplicaSet دو پاد دارد که هر کدام برنامهٔ Hello World را اجرا می‌کنند.

  2. اطلاعات Deployment را نمایش دهید:

    kubectl get deployments hello-world
kubectl describe deployments hello-world

  3. اطلاعات آبجکت‌های ReplicaSet خود را نمایش دهید:

    kubectl get replicasets
kubectl describe replicasets

  4. یک آبجکت Service ایجاد کنید که این Deployment را در دسترس قرار دهد:

    kubectl expose deployment hello-world --type=NodePort --name=example-service

  5. اطلاعات Service را نمایش دهید:

    kubectl describe services example-service

    خروجی مشابه زیر است:

    Name:                   example-service
Namespace:              default
Labels:                 run=load-balancer-example
Annotations:            <none>
Selector:               run=load-balancer-example
Type:                   NodePort
IP:                     10.32.0.16
Port:                   <unset> 8080/TCP
TargetPort:             8080/TCP
NodePort:               <unset> 31496/TCP
Endpoints:              10.200.1.4:8080,10.200.2.5:8080
Session Affinity:       None
Events:                 <none>

    مقدار NodePort این Service را یادداشت کنید. برای مثال، در خروجی بالا مقدار NodePort برابر 31496 است.

  6. پادهایی را که برنامهٔ Hello World را اجرا می‌کنند فهرست کنید:

    kubectl get pods --selector="run=load-balancer-example" --output=wide

    خروجی مشابه زیر است:

    NAME                           READY   STATUS    ...  IP           NODE
hello-world-2895499144-bsbk5   1/1     Running   ...  10.200.1.4   worker1
hello-world-2895499144-m1pwt   1/1     Running   ...  10.200.2.5   worker2

  7. نشانی IP عمومی یکی از نودهایی را که یک پاد Hello World روی آن اجرا می‌شود به دست آورید. روش به دست آوردن این نشانی به نحوهٔ راه‌اندازی کلاستر شما بستگی دارد. برای مثال، اگر از Minikube استفاده می‌کنید، می‌توانید با اجرای kubectl cluster-info نشانی نود را ببینید. اگر از نمونه‌های Google Compute Engine استفاده می‌کنید، می‌توانید با دستور gcloud compute instances list نشانی‌های عمومی نودهای خود را ببینید.

  8. روی نود انتخاب‌شده، یک قانون فایروال ایجاد کنید که ترافیک TCP را روی پورت نود مجاز کند. برای مثال، اگر مقدار NodePort سرویس شما 31568 است، یک قانون فایروال ایجاد کنید که ترافیک TCP را روی پورت 31568 مجاز کند. ارائه‌دهندگان ابری مختلف روش‌های متفاوتی برای پیکربندی قوانین فایروال ارائه می‌دهند.

  9. با استفاده از نشانی نود و پورت نود به برنامهٔ Hello World دسترسی پیدا کنید:

    curl http://<public-node-ip>:<node-port>

    در اینجا <public-node-ip> نشانی IP عمومی نود شما و <node-port> مقدار NodePort سرویس شما است. پاسخ یک درخواست موفق، یک پیام خوشامد است:

    Hello, world!
Version: 2.0.0
Hostname: hello-world-cdd4458f4-m47c8

استفاده از فایل پیکربندی Service

به‌جای استفاده از kubectl expose، می‌توانید با یک فایل پیکربندی Service یک Service ایجاد کنید.

پاکسازی

برای حذف Service، این دستور را وارد کنید:

kubectl delete services example-service

برای حذف Deployment، ReplicaSet و پادهایی که برنامهٔ Hello World را اجرا می‌کنند، این دستور را وارد کنید:

kubectl delete deployment hello-world

گام‌های بعدی

آموزش اتصال برنامه‌ها با Serviceها را دنبال کنید.
