مشارکت در مستندات کوبرنتیز

این وب‌سایت توسط Kubernetes SIG Docs نگهداری می‌شود. پروژه کوبرنتیز از کمک همه مشارکت‌کنندگان، چه تازه‌کار و چه باتجربه، استقبال می‌کند!

مشارکت‌کنندگان مستندات کوبرنتیز:

  • محتوای موجود را بهبود می‌دهند
  • محتوای جدید تولید می‌کنند
  • مستندات را ترجمه می‌کنند
  • بخش‌های مربوط به مستندات را در چرخه انتشار کوبرنتیز مدیریت و منتشر می‌کنند

تیم وبلاگ، که بخشی از SIG Docs است، در مدیریت وبلاگ‌های رسمی کمک می‌کند. برای کسب اطلاعات بیشتر، مشارکت در وبلاگ‌های کوبرنتیز را بخوانید.

توجه:

برای کسب اطلاعات بیشتر درباره مشارکت در کوبرنتیز به‌طور کلی، به وب‌سایت مستندات عمومی مشارکت‌کنندگان مراجعه کنید.

شروع کار

هر کسی می‌تواند درباره مستندات یک issue باز کند یا با ارسال یک pull request (PR) به مخزن GitHub با نام kubernetes/website تغییری را ارائه دهد. برای فعالیت مؤثر در جامعه کوبرنتیز باید با git و GitHub آشنایی کافی داشته باشید.

برای مشارکت در مستندات:

  1. موافقت‌نامه مجوز مشارکت‌کننده (Contributor License Agreement) بنیاد CNCF را امضا کنید.
  2. با مخزن مستندات و مولد سایت ایستا وب‌سایت آشنا شوید.
  3. مطمئن شوید که فرایندهای پایه‌ای باز کردن یک pull request و بازبینی تغییرات را درک کرده‌اید.

شکل ۱. شروع کار برای یک مشارکت‌کننده جدید.

شکل ۱ نقشه راهی برای مشارکت‌کنندگان جدید را نشان می‌دهد. می‌توانید برخی یا همه مراحل Sign up و Review را دنبال کنید. اکنون آماده‌اید PRهایی باز کنید که اهداف مشارکت شما را محقق می‌کنند؛ برخی از این اهداف در بخش Open PR فهرست شده‌اند. باز هم تأکید می‌کنیم که پرسش‌های شما همیشه خوش‌آمد است!

برخی وظایف به اعتماد و دسترسی بیشتری در سازمان کوبرنتیز نیاز دارند. برای جزئیات بیشتر درباره نقش‌ها و مجوزها، مشارکت در SIG Docs را ببینید.

شکل ۲. آماده‌سازی برای نخستین مشارکت شما.

  • مرور کلی مشارکت را بخوانید تا با روش‌های مختلف مشارکت آشنا شوید.
  • فهرست issueهای kubernetes/website را بررسی کنید تا issueهایی را که نقطه شروع مناسبی هستند بیابید.
  • با استفاده از GitHub یک pull request باز کنید برای مستندات موجود و درباره ثبت issue در GitHub بیشتر بیاموزید.
  • pull requestهای سایر اعضای جامعه کوبرنتیز را از نظر صحت و زبان بازبینی کنید.
  • راهنمای محتوا و راهنمای سبک نگارش کوبرنتیز را بخوانید تا بتوانید نظرات آگاهانه ارائه دهید.
  • درباره انواع محتوای صفحه و shortcodeهای Hugo بیاموزید.

دریافت کمک هنگام مشارکت

انجام نخستین مشارکت می‌تواند دشوار به نظر برسد. سفیران مشارکت‌کنندگان جدید در کنار شما هستند تا شما را در انجام چند مشارکت نخست راهنمایی کنند. می‌توانید در Slack کوبرنتیز، ترجیحاً در کانال #sig-docs، با آن‌ها در ارتباط باشید. همچنین جلسه معارفه و آشنایی مشارکت‌کنندگان جدید در اولین سه‌شنبه هر ماه برگزار می‌شود. در این جلسه می‌توانید با سفیران مشارکت‌کنندگان جدید تعامل کنید و پرسش‌های خود را حل کنید.

مشارکت در SIG Docs

SIG Docs گروهی از مشارکت‌کنندگان است که مستندات کوبرنتیز و وب‌سایت را منتشر و نگهداری می‌کنند. مشارکت در SIG Docs راهی عالی برای مشارکت‌کنندگان کوبرنتیز (چه در توسعه قابلیت‌ها و چه در سایر حوزه‌ها) است تا تأثیر بزرگی بر پروژه کوبرنتیز بگذارند.

SIG Docs از روش‌های مختلفی برای ارتباط استفاده می‌کند:

  • به کانال #sig-docs در Slack کوبرنتیز بپیوندید. حتماً خودتان را معرفی کنید!
  • به فهرست پستی kubernetes-sig-docs بپیوندید، که بحث‌های گسترده‌تر در آن انجام می‌شود و تصمیم‌های رسمی در آن ثبت می‌گردد.
  • در جلسه ویدیویی SIG Docs که هر دو هفته یک بار برگزار می‌شود شرکت کنید. این جلسات همیشه در #sig-docs اطلاع‌رسانی می‌شوند و به تقویم جلسات جامعه کوبرنتیز افزوده می‌شوند. باید کلاینت Zoom را دانلود کنید یا از طریق تلفن تماس بگیرید.
  • در هفته‌هایی که جلسه ویدیویی Zoom به‌صورت زنده برگزار نمی‌شود، در جلسه استندآپ ناهمگام SIG Docs در Slack شرکت کنید. این جلسات همیشه در #sig-docs اطلاع‌رسانی می‌شوند. تا ۲۴ ساعت پس از اعلام جلسه می‌توانید در هر یک از رشته‌گفتگوها (thread) مشارکت کنید.

سایر روش‌های مشارکت

  • از وب‌سایت جامعه کوبرنتیز دیدن کنید. در Twitter یا Stack Overflow شرکت کنید، درباره میت‌آپ‌ها و رویدادهای محلی کوبرنتیز بیاموزید و موارد دیگر.
  • برگه تقلب مشارکت‌کنندگان را بخوانید تا در توسعه قابلیت‌های کوبرنتیز مشارکت کنید.
  • از وب‌سایت مشارکت‌کنندگان دیدن کنید تا درباره مشارکت‌کنندگان کوبرنتیز و منابع بیشتر برای مشارکت‌کنندگان بیشتر بیاموزید.
  • بیاموزید چگونه در وبلاگ‌های رسمی مشارکت کنید
  • یک مطالعه موردی ارسال کنید

گام‌های بعدی

  • بیاموزید چگونه از یک کپی محلی (clone) از مخزن کار کنید.

  • قابلیت‌های یک نسخه را مستندسازی کنید.

  • در SIG Docs مشارکت کنید و عضو یا بازبین شوید.

  • در بومی‌سازی مستندات شروع به کار کنید یا به آن کمک کنید.
