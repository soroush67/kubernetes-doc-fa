Preference {#kubectl-config-k8s-io-v1alpha1-Preference}

Preference عناصر فایل پیکربندی KubeRC را ذخیره می‌کند.

FieldDescription
apiVersion
string		kubectl.config.k8s.io/v1alpha1
kind
string		Preference
overrides [Required]
[]CommandDefaults

overrides امکان تغییر مقادیر پیش‌فرض فلگ‌های دستورها را فراهم می‌کند. این قابلیت به‌ویژه زمانی مفید است که کاربر نمی‌خواهد هر بار فلگ‌ها را به‌صورت صریح تنظیم کند.
aliases [Required]
[]AliasOverride

aliases امکان تعریف نام‌های مستعار (alias) دستور را برای دستورهای موجود kubectl، همراه با مقادیر پیش‌فرض اختیاری فلگ‌ها فراهم می‌کند. اگر نام alias با یکی از دستورهای داخلی (built-in) تداخل داشته باشد، دستور داخلی همیشه اولویت دارد. بازنویسی‌های فلگ که در بخش overrides تعریف شده‌اند، برای aliasهای مربوط به همان دستور اعمال نمی‌شوند. عبارت kubectl [ALIAS NAME] [USER_FLAGS] [USER_EXPLICIT_ARGS] به شکل زیر گسترش می‌یابد: kubectl [COMMAND] # دستور داخلی که alias به آن اشاره می‌کند [KUBERC_PREPEND_ARGS] [USER_FLAGS] [KUBERC_FLAGS] # بقیهٔ فلگ‌هایی که کاربر در [USER_FLAGS] ارائه نکرده است [USER_EXPLICIT_ARGS] [KUBERC_APPEND_ARGS] برای مثال:

  • name: runx command: run flags:
    • name: image default: nginx appendArgs:
    • custom-arg1 برای مثال، اگر کاربر دستور "kubectl runx test-pod" را اجرا کند، این دستور به "kubectl run --image=nginx test-pod -- custom-arg1" گسترش می‌یابد.
  • name: getn command: get flags:
    • name: output default: wide prependArgs:
    • node دستور "kubectl getn control-plane-1" به "kubectl get node control-plane-1 --output=wide" گسترش می‌یابد و دستور "kubectl getn control-plane-1 --output=json" به "kubectl get node --output=json control-plane-1" گسترش می‌یابد.

AliasOverride {#kubectl-config-k8s-io-v1alpha1-AliasOverride}

ظاهر می‌شود در:

  • Preference

AliasOverride تعریف‌های alias را ذخیره می‌کند.

FieldDescription
name [Required]
string

name نام alias است و فقط می‌تواند شامل نویسه‌های الفبایی باشد. اگر نام alias با یک دستور داخلی تداخل داشته باشد، دستور داخلی استفاده خواهد شد.
command [Required]
string

command یک دستور یا مجموعه‌ای از دستورها برای اجراست، مانند "set env" یا "create".
prependArgs [Required]
[]string

prependArgs آرگومان‌هایی مانند نام منبع‌ها و موارد مشابه را ذخیره می‌کند. این آرگومان‌ها پس از نام alias درج می‌شوند.
appendArgs [Required]
[]string

appendArgs آرگومان‌هایی مانند نام منبع‌ها و موارد مشابه را ذخیره می‌کند. این آرگومان‌ها به انتهای USER_ARGS افزوده می‌شوند.
flags [Required]
[]CommandOptionDefault

flags برای ذخیرهٔ تعریف‌های فلگ مربوط به alias در نظر گرفته شده است. flags فقط مقدار پیش‌فرض فلگ را تغییر می‌دهد و اگر کاربر مقداری را به‌صورت صریح ارائه کند، همان مقدار صریح استفاده می‌شود.

CommandDefaults {#kubectl-config-k8s-io-v1alpha1-CommandDefaults}

ظاهر می‌شود در:

  • Preference

CommandDefaults دستورها و مقادیر پیش‌فرض گزینه‌های مرتبط با آن‌ها را ذخیره می‌کند.

FieldDescription
command [Required]
string

command به دستوری اشاره می‌کند که مقدار پیش‌فرض فلگ آن تغییر می‌یابد.
flags [Required]
[]CommandOptionDefault

flags فهرستی از فلگ‌هاست که مقادیر پیش‌فرض متفاوتی را ذخیره می‌کنند.

CommandOptionDefault {#kubectl-config-k8s-io-v1alpha1-CommandOptionDefault}

ظاهر می‌شود در:

  • AliasOverride

  • CommandDefaults

CommandOptionDefault نام و مقدار پیش‌فرض مشخص‌شدهٔ یک گزینه را ذخیره می‌کند.

FieldDescription
name [Required]
string

نام فلگ (به شکل بلند و بدون خط تیره).
default [Required]
string

مقدار پیش‌فرض به‌صورت رشته. این مقدار توسط kubectl به مقدار سازگار با فلگ تبدیل (parse) می‌شود.
