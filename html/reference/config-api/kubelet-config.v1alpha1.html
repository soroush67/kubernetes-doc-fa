CredentialProviderConfig {#kubelet-config-k8s-io-v1alpha1-CredentialProviderConfig}

CredentialProviderConfig پیکربندی‌ای است که اطلاعات مربوط به هر یک از ارائه‌دهندگان اعتبارنامه مبتنی بر exec را در بر دارد. Kubelet این پیکربندی را از دیسک می‌خواند و هر ارائه‌دهنده را مطابق با آنچه توسط نوع CredentialProvider مشخص شده است فعال می‌کند.

فیلدتوضیحات
apiVersion
string		kubelet.config.k8s.io/v1alpha1
kind
string		CredentialProviderConfig
providers [الزامی]
[]CredentialProvider

providers فهرستی از افزونه‌های ارائه‌دهنده اعتبارنامه است که توسط kubelet فعال خواهند شد. چند ارائه‌دهنده ممکن است با یک ایمیج واحد مطابقت پیدا کنند؛ در این صورت اعتبارنامه‌های همه ارائه‌دهندگان به kubelet بازگردانده می‌شود. اگر برای یک ایمیج واحد چند ارائه‌دهنده فراخوانی شوند، نتایج با یکدیگر ترکیب می‌شوند. اگر ارائه‌دهندگان کلیدهای احراز هویت هم‌پوشان بازگردانند، مقدار ارائه‌دهنده‌ای که در این فهرست زودتر آمده است ابتدا امتحان می‌شود.

ImagePullIntent {#kubelet-config-k8s-io-v1alpha1-ImagePullIntent}

ImagePullIntent رکوردی از تلاش kubelet برای pull کردن یک ایمیج است.

فیلدتوضیحات
apiVersion
string		kubelet.config.k8s.io/v1alpha1
kind
string		ImagePullIntent
image [الزامی]
string

Image مشخصات ایمیج است که از فیلد image یک کانتینر گرفته می‌شود. نام فایل، هش SHA-256 این مقدار است. این کار برای پرهیز از کاراکترهایی است که در نام فایل ناامن‌اند، مانند ':' و '/'.

ImagePulledRecord {#kubelet-config-k8s-io-v1alpha1-ImagePulledRecord}

ImagePullRecord رکوردی از یک ایمیج است که توسط kubelet pull شده است.

اگر هیچ رکوردی در فیلد kubernetesSecrets وجود نداشته باشد و هر دو فیلد nodeWideCredentials و anonymous برابر false باشند، اعتبارنامه‌ها باید در دفعه بعدی که ایمیجِ نمایان‌شده توسط این رکورد درخواست می‌شود، دوباره بررسی شوند.

فیلدتوضیحات
apiVersion
string		kubelet.config.k8s.io/v1alpha1
kind
string		ImagePulledRecord
lastUpdatedTime [الزامی]
meta/v1.Time

LastUpdatedTime زمان آخرین به‌روزرسانی این رکورد است.
imageRef [الزامی]
string

ImageRef ارجاعی به ایمیجی است که این فایل نمایانگر آن است و از CRI دریافت شده است. نام فایل، هش SHA-256 این مقدار است. این کار برای پرهیز از کاراکترهایی است که در نام فایل ناامن‌اند، مانند ':' و '/'.
credentialMapping [الزامی]
map[string]ImagePullCredentials

CredentialMapping مقدار image را به مجموعه اعتبارنامه‌هایی نگاشت می‌کند که پیش‌تر با آن‌ها pull شده است. image در این‌جا محتوای فیلد image کانتینر یک Pod است که تگ/digest آن حذف شده است.

مثال: کانتینر ایمیج hello-world:latest@sha256:91fb4b041da273d5a3273b6d587d62d518300a6ad268b28628f74997b93171b2 را درخواست می‌کند: "credentialMapping": { "hello-world": { "nodePodsAccessible": true } }

CredentialProvider {#kubelet-config-k8s-io-v1alpha1-CredentialProvider}

نمایش داده شده در:

  • CredentialProviderConfig

CredentialProvider نمایانگر یک افزونه exec است که kubelet آن را فراخوانی می‌کند. افزونه فقط زمانی فراخوانی می‌شود که ایمیجِ در حال pull با ایمیج‌هایی که افزونه مدیریت می‌کند مطابقت داشته باشد (به matchImages مراجعه کنید).

فیلدتوضیحات
name [الزامی]
string

name نام الزامی ارائه‌دهنده اعتبارنامه است. این نام باید با نام فایل اجرایی ارائه‌دهنده، آن‌گونه که kubelet می‌بیند، مطابقت داشته باشد. فایل اجرایی باید در دایرکتوری bin مربوط به kubelet باشد (که با فلگ --image-credential-provider-bin-dir تنظیم می‌شود). این نام باید میان همه ارائه‌دهندگان یکتا باشد.
matchImages [الزامی]
[]string

matchImages فهرستی الزامی از رشته‌هاست که برای تطبیق با ایمیج‌ها به کار می‌رود تا مشخص شود آیا این ارائه‌دهنده باید فراخوانی شود یا نه. اگر یکی از رشته‌ها با ایمیج درخواست‌شده از سوی kubelet مطابقت داشته باشد، افزونه فراخوانی می‌شود و فرصت می‌یابد اعتبارنامه ارائه دهد. انتظار می‌رود ایمیج‌ها شامل دامنه رجیستری و مسیر URL باشند.

هر مورد در matchImages یک الگو است که می‌تواند به‌طور اختیاری شامل پورت و مسیر باشد. Globها را می‌توان در دامنه به کار برد، اما در پورت یا مسیر نمی‌توان. Globها به‌صورت زیردامنه‌هایی مانند *.k8s.io یا k8s.*.io و دامنه‌های سطح بالا مانند k8s.* پشتیبانی می‌شوند. تطبیق زیردامنه‌های جزئی مانند app*.k8s.io نیز پشتیبانی می‌شود. هر glob فقط می‌تواند با یک بخش زیردامنه مطابقت پیدا کند، بنابراین *.io با *.k8s.io مطابقت ندارد.

میان یک ایمیج و یک matchImage زمانی تطبیق وجود دارد که همه شرایط زیر برقرار باشند:

  • هر دو تعداد بخش‌های دامنه یکسانی داشته باشند و هر بخش مطابقت داشته باشد.
  • مسیر URL مربوط به imageMatch باید پیشوندی از مسیر URL ایمیج هدف باشد.
  • اگر imageMatch شامل پورت باشد، پورت باید در ایمیج نیز مطابقت داشته باشد.

نمونه مقادیر matchImages:

  • 123456789.dkr.ecr.us-east-1.amazonaws.com
  • *.azurecr.io
  • gcr.io
  • *.*.registry.io
  • registry.io:8080/path
defaultCacheDuration [الزامی]
meta/v1.Duration

defaultCacheDuration مدت زمان پیش‌فرضی است که افزونه اعتبارنامه‌ها را در حافظه نگهداری (cache) می‌کند، در صورتی که مدت نگهداری در پاسخ افزونه ارائه نشده باشد. این فیلد الزامی است.
apiVersion [الزامی]
string

نسخه ورودی الزامی برای CredentialProviderRequest مربوط به exec. CredentialProviderResponse بازگردانده‌شده باید حتماً از همان نسخه کدگذاری ورودی استفاده کند. مقادیر پشتیبانی‌شده فعلی عبارت‌اند از:

  • credentialprovider.kubelet.k8s.io/v1alpha1
args
[]string

آرگومان‌هایی که هنگام اجرای دستور به آن ارسال می‌شوند.
env
[]ExecEnvVar

Env متغیرهای محیطی اضافی را که باید در اختیار پروسه قرار گیرند تعریف می‌کند. این‌ها با محیط میزبان و همچنین متغیرهایی که client-go برای ارسال آرگومان به افزونه استفاده می‌کند، اجتماع می‌شوند.

ImagePullCredentials {#kubelet-config-k8s-io-v1alpha1-ImagePullCredentials}

نمایش داده شده در:

  • ImagePulledRecord

ImagePullCredentials اعتبارنامه‌هایی را توصیف می‌کند که می‌توان برای pull کردن یک ایمیج از آن‌ها استفاده کرد.

فیلدتوضیحات
kubernetesSecrets
[]ImagePullSecret

KuberneteSecretCoordinates فهرستی از مختصات همه Secretهای کوبرنتیز است که برای pull کردن ایمیج استفاده شده‌اند.
kubernetesServiceAccounts
[]ImagePullServiceAccount

KubernetesServiceAccounts فهرستی از مختصات همه service accountهای کوبرنتیز است که برای pull کردن ایمیج استفاده شده‌اند.
nodePodsAccessible
bool

NodePodsAccessible پرچمی است که نشان می‌دهد اعتبارنامه‌های pull برای همه Podهای روی نود قابل دسترسی‌اند، یا اینکه برای pull به هیچ اعتبارنامه‌ای نیاز نیست.

اگر true باشد، با فیلد kubernetesSecrets متقابلاً ناسازگار است (نمی‌توانند هم‌زمان تنظیم شوند).
