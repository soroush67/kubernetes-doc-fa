ClientConnectionConfiguration {#ClientConnectionConfiguration}

در این بخش‌ها ظاهر می‌شود:

  • KubeSchedulerConfiguration

  • GenericControllerManagerConfiguration

ClientConnectionConfiguration شامل جزئیات لازم برای ساخت یک کلاینت است.

فیلدتوضیحات
kubeconfig [الزامی]
string

kubeconfig مسیر یک فایل KubeConfig است.
acceptContentTypes [الزامی]
string

acceptContentTypes هدر Accept را که کلاینت‌ها هنگام اتصال به یک سرور ارسال می‌کنند تعریف می‌کند و مقدار پیش‌فرض 'application/json' را بازنویسی می‌کند. این فیلد تمام اتصال‌هایی را که یک کلاینت مشخص به سرور برقرار می‌کند کنترل می‌کند.
contentType [الزامی]
string

contentType نوع محتوایی است که هنگام ارسال داده از این کلاینت به سرور استفاده می‌شود.
qps [الزامی]
float32

qps تعداد کوئری‌های مجاز در هر ثانیه برای این اتصال را کنترل می‌کند.
burst [الزامی]
int32

burst در صورتی که کلاینت از نرخ مجاز خود فراتر برود، اجازه می‌دهد کوئری‌های اضافی انباشته شوند.

LeaderElectionConfiguration {#LeaderElectionConfiguration}

در این بخش‌ها ظاهر می‌شود:

  • KubeSchedulerConfiguration

  • GenericControllerManagerConfiguration

LeaderElectionConfiguration پیکربندی کلاینت‌های انتخاب رهبر (leader election) را برای مؤلفه‌هایی تعریف می‌کند که می‌توانند با فعال بودن انتخاب رهبر اجرا شوند.

فیلدتوضیحات
leaderElect [الزامی]
bool

leaderElect باعث می‌شود یک کلاینت انتخاب رهبر پیش از اجرای حلقه اصلی، رهبری را به دست آورد. هنگام اجرای مؤلفه‌های تکثیرشده برای دسترس‌پذیری بالا، این گزینه را فعال کنید.
leaseDuration [الزامی]
meta/v1.Duration

leaseDuration مدت زمانی است که کاندیداهای غیررهبر، پس از مشاهده تمدید رهبری، منتظر می‌مانند تا برای به دست آوردن رهبری یک جایگاه رهبری که اشغال شده اما تمدید نشده است اقدام کنند. این مقدار در عمل بیشترین مدت زمانی است که یک رهبر می‌تواند متوقف باشد تا کاندیدای دیگری جایگزین او شود. این فیلد فقط زمانی کاربرد دارد که انتخاب رهبر فعال باشد.
renewDeadline [الزامی]
meta/v1.Duration

renewDeadline فاصله زمانی بین تلاش‌های رهبر فعلی (acting master) برای تمدید جایگاه رهبری است، پیش از آنکه از رهبری دست بکشد. این مقدار باید کمتر از مدت lease یا برابر با آن باشد. این فیلد فقط زمانی کاربرد دارد که انتخاب رهبر فعال باشد.
retryPeriod [الزامی]
meta/v1.Duration

retryPeriod مدت زمانی است که کلاینت‌ها باید بین تلاش‌های کسب و تمدید رهبری منتظر بمانند. این فیلد فقط زمانی کاربرد دارد که انتخاب رهبر فعال باشد.
resourceLock [الزامی]
string

resourceLock نوع آبجکت منبعی را مشخص می‌کند که برای قفل‌کردن در چرخه‌های انتخاب رهبر استفاده می‌شود.
resourceName [الزامی]
string

resourceName نام آبجکت منبعی را مشخص می‌کند که برای قفل‌کردن در چرخه‌های انتخاب رهبر استفاده می‌شود.
resourceNamespace [الزامی]
string

resourceName فضای نام (namespace) آبجکت منبعی را مشخص می‌کند که برای قفل‌کردن در چرخه‌های انتخاب رهبر استفاده می‌شود.
