sourceIPs
[]string

IPهای مبدأ، یعنی جایی که درخواست از آن آغاز شده و پروکسی‌های میانی. IPهای مبدأ به ترتیب زیر فهرست می‌شوند:

  1. IPهای موجود در هدر درخواست X-Forwarded-For
  2. هدر X-Real-Ip، در صورتی که در فهرست X-Forwarded-For وجود نداشته باشد
  3. آدرس راه دور (remote address) اتصال، در صورتی که با آخرین IP موجود در فهرست تا این مرحله (X-Forwarded-For یا X-Real-Ip) مطابقت نداشته باشد. توجه: همه IPها به‌جز آخرین مورد می‌توانند به‌صورت دلخواه توسط کلاینت تنظیم شوند.
userAgent
string

UserAgent رشته user agent گزارش‌شده توسط کلاینت را ثبت می‌کند. توجه کنید که UserAgent را کلاینت ارائه می‌کند و نباید به آن اعتماد کرد.
objectRef
ObjectReference

ارجاع به آبجکتی که این درخواست آن را هدف قرار داده است. برای درخواست‌های از نوع List یا درخواست‌های غیرمنبعی کاربرد ندارد.
responseStatus
meta/v1.Status

وضعیت پاسخ؛ حتی زمانی که ResponseObject از نوع Status نباشد نیز مقداردهی می‌شود. برای پاسخ‌های موفق، این مقدار فقط شامل Code و StatusSuccess خواهد بود. برای پاسخ‌های خطا که از نوع status نیستند، این مقدار به‌صورت خودکار با Message خطا پر می‌شود.
requestObject
k8s.io/apimachinery/pkg/runtime.Unknown

آبجکت API موجود در درخواست، با قالب JSON. RequestObject همان‌گونه که در درخواست آمده است (و احتمالاً دوباره با JSON کدگذاری شده) و پیش از تبدیل نسخه، اعمال مقادیر پیش‌فرض، admission یا ادغام (merge) ثبت می‌شود. این یک نوع آبجکت نسخه‌دار خارجی است و ممکن است به‌تنهایی آبجکتی معتبر نباشد. برای درخواست‌های غیرمنبعی حذف می‌شود. فقط در سطح Request و بالاتر ثبت می‌شود.
responseObject
k8s.io/apimachinery/pkg/runtime.Unknown

آبجکت API بازگردانده‌شده در پاسخ، با قالب JSON. ResponseObject پس از تبدیل به نوع خارجی ثبت و به‌صورت JSON سریالایز می‌شود. برای درخواست‌های غیرمنبعی حذف می‌شود. فقط در سطح Response ثبت می‌شود.
requestReceivedTimestamp
meta/v1.MicroTime

زمانی که درخواست به apiserver رسیده است.
stageTimestamp
meta/v1.MicroTime

زمانی که درخواست به مرحله ممیزی فعلی رسیده است.
annotations
map[string]string

Annotations یک نگاشت کلید-مقدار بدون ساختار است که همراه با رویداد ممیزی ذخیره می‌شود و ممکن است توسط افزونه‌های فراخوانی‌شده در زنجیره پاسخ‌گویی به درخواست، از جمله افزونه‌های احراز هویت، مجوزدهی و admission تنظیم شود. توجه کنید که این annotationها مربوط به رویداد ممیزی هستند و با metadata.annotations آبجکت ارسال‌شده متناظر نیستند. کلیدها باید مؤلفه اطلاع‌دهنده را به‌طور یکتا مشخص کنند تا از تداخل نام‌ها جلوگیری شود (برای مثال podsecuritypolicy.admission.k8s.io/policy). مقادیر باید کوتاه باشند. Annotationها در سطح Metadata گنجانده می‌شوند.

Policy {#audit-k8s-io-v1-Policy}

در این بخش‌ها ظاهر می‌شود:

  • PolicyList

Policy پیکربندی ثبت لاگ ممیزی و قوانین مربوط به نحوه ثبت دسته‌های مختلف درخواست‌ها را تعریف می‌کند.

فیلدتوضیحات
apiVersion
string		audit.k8s.io/v1
kind
string		Policy
metadata
meta/v1.ObjectMeta

ObjectMeta برای سازگاری با زیرساخت API گنجانده شده است.

برای فیلدهای metadata به مستندات API کوبرنتیز مراجعه کنید.
rules [الزامی]
[]PolicyRule

Rules مشخص می‌کنند که یک درخواست باید در کدام سطح ممیزی (Level) ثبت شود. یک درخواست ممکن است با چندین قانون مطابقت داشته باشد؛ در این صورت، اولین قانون منطبق استفاده می‌شود. سطح ممیزی پیش‌فرض None است، اما می‌توان آن را با یک قانون فراگیر (catch-all) در انتهای فهرست بازنویسی کرد. PolicyRuleها کاملاً مرتب‌شده هستند.
omitStages
[]Stage

OmitStages فهرستی از مراحل است که برای آن‌ها هیچ رویدادی ایجاد نمی‌شود. توجه کنید که این مورد را می‌توان برای هر قانون نیز مشخص کرد؛ در آن صورت، اجتماع هر دو حذف می‌شود.
omitManagedFields
bool

OmitManagedFields مشخص می‌کند که آیا فیلدهای مدیریت‌شده (managed fields) در بدنه درخواست و پاسخ از نوشته شدن در لاگ ممیزی API حذف شوند یا خیر. این فیلد به‌عنوان مقدار پیش‌فرض سراسری استفاده می‌شود؛ مقدار 'true' فیلدهای مدیریت‌شده را حذف می‌کند، و در غیر این صورت فیلدهای مدیریت‌شده در لاگ ممیزی API گنجانده می‌شوند. توجه کنید که این مورد را می‌توان برای هر قانون نیز مشخص کرد؛ در آن صورت مقداری که در یک قانون تعیین شده است، مقدار پیش‌فرض سراسری را بازنویسی می‌کند.

GroupResources {#audit-k8s-io-v1-GroupResources}

در این بخش‌ها ظاهر می‌شود:

  • PolicyRule

GroupResources نشان‌دهنده انواع منابع در یک گروه API است.

فیلدتوضیحات
group
string

Group نام گروه API است که منابع را در بر می‌گیرد. رشته خالی نشان‌دهنده گروه API هسته (core) است. * با همه گروه‌ها مطابقت دارد.
resources
[]string

Resources فهرستی از منابعی است که این قانون روی آن‌ها اعمال می‌شود.

برای مثال:

  • pods با podها مطابقت دارد.
  • pods/log با زیرمنبع log مربوط به podها مطابقت دارد.
  • * با همه منابع و زیرمنابع آن‌ها مطابقت دارد.
  • pods/* با همه زیرمنابع podها مطابقت دارد.
  • */scale با همه زیرمنابع scale مطابقت دارد.

اگر wildcard وجود داشته باشد، قانون اعتبارسنجی اطمینان حاصل می‌کند که منابع با یکدیگر همپوشانی نداشته باشند.

فهرست خالی به این معناست که همه منابع و زیرمنابع در این گروه‌های API اعمال می‌شوند.
resourceNames
[]string

ResourceNames فهرستی از نام نمونه‌های منبع است که سیاست با آن‌ها مطابقت دارد. استفاده از این فیلد مستلزم مشخص کردن Resources است. فهرست خالی به این معناست که با هر نمونه از منبع مطابقت دارد.

PolicyRule {#audit-k8s-io-v1-PolicyRule}

در این بخش‌ها ظاهر می‌شود:

  • Policy

PolicyRule درخواست‌ها را بر اساس فراداده (metadata) به یک سطح ممیزی (Level) نگاشت می‌کند. درخواست‌ها باید با قوانین هر فیلد مطابقت داشته باشند (اشتراک قوانین).

فیلدتوضیحات
level [الزامی]
Level

سطحی (Level) که درخواست‌های منطبق با این قانون در آن ثبت می‌شوند.
users
[]string

کاربرانی (بر اساس نام کاربر احراز هویت‌شده) که این قانون روی آن‌ها اعمال می‌شود. فهرست خالی به این معناست که همه کاربران را شامل می‌شود.
userGroups
[]string

گروه‌های کاربری که این قانون روی آن‌ها اعمال می‌شود. کاربر در صورتی منطبق در نظر گرفته می‌شود که عضو هر یک از UserGroups باشد. فهرست خالی به این معناست که همه گروه‌های کاربری را شامل می‌شود.
verbs
[]string

فعل‌هایی (verbs) که با این قانون مطابقت دارند. فهرست خالی به این معناست که همه فعل‌ها را شامل می‌شود.
resources
[]GroupResources

منابعی که این قانون با آن‌ها مطابقت دارد. فهرست خالی به این معناست که همه انواع در همه گروه‌های API را شامل می‌شود.
namespaces
[]string

فضاهای نام (Namespaces) که این قانون با آن‌ها مطابقت دارد. رشته خالی "" با منابعی که به فضای نام تعلق ندارند (non-namespaced) مطابقت دارد. فهرست خالی به این معناست که همه فضاهای نام را شامل می‌شود.
nonResourceURLs
[]string

NonResourceURLs مجموعه‌ای از مسیرهای URL است که باید ممیزی شوند. استفاده از * مجاز است، اما فقط به‌عنوان گام کامل و پایانی مسیر. مثال‌ها:

  • /metrics - ثبت درخواست‌های مربوط به متریک‌های apiserver
  • /healthz* - ثبت همه بررسی‌های سلامت (health checks)
omitStages
[]Stage

OmitStages فهرستی از مراحل است که برای آن‌ها هیچ رویدادی ایجاد نمی‌شود. توجه کنید که این مورد را می‌توان در سطح کل سیاست نیز مشخص کرد؛ در آن صورت، اجتماع هر دو حذف می‌شود. فهرست خالی به این معناست که هیچ محدودیتی اعمال نخواهد شد.
omitManagedFields
bool

OmitManagedFields مشخص می‌کند که آیا فیلدهای مدیریت‌شده (managed fields) در بدنه درخواست و پاسخ از نوشته شدن در لاگ ممیزی API حذف شوند یا خیر.

  • مقدار 'true' فیلدهای مدیریت‌شده را از لاگ ممیزی API حذف می‌کند
  • مقدار 'false' نشان می‌دهد که فیلدهای مدیریت‌شده باید در لاگ ممیزی API گنجانده شوند توجه کنید که مقدار مشخص‌شده در این قانون، در صورت وجود، مقدار پیش‌فرض سراسری را بازنویسی می‌کند و اگر مقداری مشخص نشده باشد، مقدار پیش‌فرض سراسری که در Policy.OmitManagedFields تعیین شده است معتبر خواهد بود.
