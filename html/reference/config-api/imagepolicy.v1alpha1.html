ImageReview {#imagepolicy-k8s-io-v1alpha1-ImageReview}

ImageReview بررسی می‌کند که آیا مجموعه ایمیج‌های موجود در یک Pod مجاز هستند یا خیر.

FieldDescription
apiVersion
string		imagepolicy.k8s.io/v1alpha1
kind
string		ImageReview
metadata
meta/v1.ObjectMeta

metadata فراداده استاندارد آبجکت است. اطلاعات بیشتر: https://git.k8s.io/community/contributors/devel/sig-architecture/api-conventions.md#metadata

برای مشاهده فیلدهای metadata به مستندات API کوبرنتیز مراجعه کنید.
spec
ImageReviewSpec

spec شامل اطلاعاتی درباره Podی است که در حال ارزیابی است.
status
ImageReviewStatus

status توسط بک‌اند تکمیل می‌شود و نشان می‌دهد که آیا Pod باید مجاز شناخته شود یا خیر.

ImageReviewContainerSpec {#imagepolicy-k8s-io-v1alpha1-ImageReviewContainerSpec}

Appears in:

  • ImageReviewSpec

ImageReviewContainerSpec توصیف یک کانتینر در درخواست ایجاد Pod است.

FieldDescription
image
string

image می‌تواند به شکل image:tag یا image@SHA:012345679abcdef باشد.

ImageReviewSpec {#imagepolicy-k8s-io-v1alpha1-ImageReviewSpec}

Appears in:

  • ImageReview

ImageReviewSpec توصیف درخواست ایجاد Pod است.

FieldDescription
containers
[]ImageReviewContainerSpec

containers فهرستی از زیرمجموعه‌ای از اطلاعات هر کانتینر در Podی است که در حال ایجاد می‌باشد.
annotations
map[string]string

annotations فهرستی از جفت‌های کلید-مقدار است که از حاشیه‌نویسی‌های (annotations) Pod استخراج شده‌اند. این فهرست فقط شامل کلیدهایی است که با الگوی *.image-policy.k8s.io/* مطابقت دارند. تصمیم‌گیری درباره نحوه تفسیر این annotationها، در صورت لزوم، بر عهده هر بک‌اند webhook است.
namespace
string

namespace فضای نامی (namespace) است که Pod در آن ایجاد می‌شود.

ImageReviewStatus {#imagepolicy-k8s-io-v1alpha1-ImageReviewStatus}

Appears in:

  • ImageReview

ImageReviewStatus نتیجه بررسی درخواست ایجاد Pod است.

FieldDescription
allowed
bool

allowed نشان می‌دهد که اجرای همه ایمیج‌ها مجاز شمرده شده است.
reason
string

reason باید خالی باشد، مگر زمانی که Allowed مقدار false داشته باشد؛ در این صورت ممکن است شامل توضیح کوتاهی درباره مشکل باشد. کوبرنتیز ممکن است خطاهای بسیار طولانی را هنگام نمایش به کاربر کوتاه کند.
auditAnnotations
map[string]string

auditAnnotations با استفاده از 'AddAnnotation' به آبجکت attributes درخواست admission controller افزوده می‌شود. کلیدها باید بدون پیشوند باشند (یعنی admission controller پیشوند مناسب را خودش اضافه می‌کند).
