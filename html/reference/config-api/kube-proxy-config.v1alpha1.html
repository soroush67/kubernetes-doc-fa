LoggingConfiguration {#LoggingConfiguration}

در این موارد ظاهر می‌شود:

  • KubeletConfiguration

LoggingConfiguration شامل گزینه‌های گزارش‌گیری (logging) است.

فیلدتوضیحات
format [الزامی]
string

Format Flag ساختار پیام‌های گزارش را مشخص می‌کند. مقدار پیش‌فرض format برابر text است.
flushFrequency [الزامی]
TimeOrMetaDuration

بیشترین زمان مجاز بین دو عملیات flush گزارش‌ها. اگر مقدار از نوع رشته باشد، به‌عنوان یک بازه زمانی (duration) تفسیر می‌شود (برای مثال "1s"). اگر مقدار از نوع عدد صحیح باشد، بیشترین تعداد نانوثانیه را مشخص می‌کند (برای مثال 1s = 1000000000). اگر بک‌اند گزارش‌گیری انتخاب‌شده پیام‌های گزارش را بدون بافر بنویسد، این مقدار نادیده گرفته می‌شود.
verbosity [الزامی]
VerbosityLevel

Verbosity آستانه‌ای است که تعیین می‌کند کدام پیام‌های گزارش ثبت شوند. مقدار پیش‌فرض صفر است که فقط مهم‌ترین پیام‌ها را ثبت می‌کند. مقادیر بالاتر پیام‌های بیشتری را فعال می‌کنند. پیام‌های خطا همیشه ثبت می‌شوند.
vmodule [الزامی]
VModuleConfiguration

VModule آستانه verbosity را برای فایل‌های منفرد بازنویسی می‌کند. فقط برای قالب گزارش "text" پشتیبانی می‌شود.
options [الزامی]
FormatOptions

[آلفا] Options شامل پارامترهای اضافی است که مختص قالب‌های مختلف گزارش‌گیری هستند. فقط گزینه‌های قالب انتخاب‌شده استفاده می‌شوند، اما همه آن‌ها اعتبارسنجی می‌شوند. فقط زمانی در دسترس است که feature gate با نام LoggingAlphaOptions فعال باشد.

LeaderElectionConfiguration {#LeaderElectionConfiguration}

در این موارد ظاهر می‌شود:

  • KubeSchedulerConfiguration

  • GenericControllerManagerConfiguration

LeaderElectionConfiguration پیکربندی کلاینت‌های انتخاب رهبر (leader election) را برای مؤلفه‌هایی که می‌توانند با فعال بودن leader election اجرا شوند تعریف می‌کند.

فیلدتوضیحات
leaderElect [الزامی]
bool

leaderElect باعث می‌شود یک کلاینت انتخاب رهبر پیش از اجرای حلقه اصلی، رهبری را به دست آورد. این گزینه را هنگام اجرای مؤلفه‌های replicated برای دستیابی به دسترس‌پذیری بالا فعال کنید.
leaseDuration [الزامی]
meta/v1.Duration

leaseDuration مدت زمانی است که نامزدهای غیررهبر پس از مشاهده تمدید رهبری صبر می‌کنند تا برای کسب رهبری یک جایگاه رهبری که اشغال شده اما تمدید نشده است اقدام کنند. این مقدار در عمل بیشترین مدتی است که یک رهبر می‌تواند متوقف باشد پیش از آنکه نامزد دیگری جایگزین آن شود. فقط در صورتی کاربرد دارد که leader election فعال باشد.
renewDeadline [الزامی]
meta/v1.Duration

renewDeadline فاصله زمانی بین تلاش‌های master فعلی برای تمدید جایگاه رهبری پیش از آن است که از رهبری دست بکشد. این مقدار باید کمتر از یا برابر با مدت lease باشد. فقط در صورتی کاربرد دارد که leader election فعال باشد.
retryPeriod [الزامی]
meta/v1.Duration

retryPeriod مدت زمانی است که کلاینت‌ها باید بین تلاش‌های کسب و تمدید رهبری صبر کنند. فقط در صورتی کاربرد دارد که leader election فعال باشد.
resourceLock [الزامی]
string

resourceLock نوع آبجکت منبعی را مشخص می‌کند که برای قفل کردن در چرخه‌های انتخاب رهبر استفاده می‌شود.
resourceName [الزامی]
string

resourceName نام آبجکت منبعی را مشخص می‌کند که برای قفل کردن در چرخه‌های انتخاب رهبر استفاده می‌شود.
resourceNamespace [الزامی]
string

resourceName فضای نام (namespace) آبجکت منبعی را مشخص می‌کند که برای قفل کردن در چرخه‌های انتخاب رهبر استفاده می‌شود.

string

metricsBindAddress [Required]
string

metricsBindAddress آدرس IP و پورتی است که سرور متریک‌ها روی آن سرویس‌دهی می‌کند و مقدار پیش‌فرض آن "127.0.0.1:10249" است (اگر bindAddress تنظیم نشده باشد یا IPv4 باشد)، یا "[::1]:10249" (اگر bindAddress از نوع IPv6 باشد). (برای اتصال به همه‌ی اینترفیس‌ها، مقدار را روی "0.0.0.0:10249" / "[::]:10249" تنظیم کنید.)
bindAddressHardFail [Required]
bool

bindAddressHardFail در صورت true بودن، به kube-proxy می‌گوید که ناکامی در اتصال به یک پورت را خطای مرگبار تلقی کند و خارج شود.
enableProfiling [Required]
bool

enableProfiling پروفایل‌گیری از طریق رابط وب را روی handler مربوط به /debug/pprof فعال می‌کند. handlerهای پروفایل‌گیری توسط سرور متریک‌ها مدیریت می‌شوند.

clusterCIDR محدوده‌ی CIDR پادهای کلاستر است. (برای کلاسترهای dual-stack می‌توان یک جفت محدوده‌ی CIDR جداشده با ویرگول برای dual-stack تعیین کرد.) وقتی DetectLocalMode روی ClusterCIDR تنظیم شده باشد، kube-proxy ترافیکی را محلی در نظر می‌گیرد که IP مبدأ آن در این محدوده باشد. (در غیر این صورت از این فیلد استفاده نمی‌شود.)
nodePortAddresses [Required]
[]string

nodePortAddresses فهرستی از محدوده‌های CIDR و/یا کلیدواژه‌هایی است که به محدوده‌های CIDR بسط می‌یابند. سرویس‌های NodePort فقط روی IPهای نودی که در این فهرست پوشش داده شده‌اند در دسترس هستند. کلیدواژه‌های پشتیبانی‌شده: 'primary' (آدرس‌های IPv4 و/یا IPv6 اصلی آبجکت Node)، 'localhost' (‏127.0.0.0/8 و ::1/128) و 'all' (‏0.0.0.0/0 و ::/0). هر ترکیبی از کلیدواژه‌ها و CIDRهای معتبر را می‌توان در فهرست قرار داد.

سرویس‌دهی NodePortها روی IPهای loopback فقط در حالت iptables پشتیبانی می‌شود (فقط IPv4، به iptables.localhostNodePorts مراجعه کنید)، و در حالت nftables فقط برای TCP و هنگامی که feature gate با نام KubeProxyNFTablesLocalhostNodePorts فعال باشد و فهرست به‌صراحت loopback را شامل شود (برای مثال 'localhost').

اگر تنظیم نشود، مقدار پیش‌فرض در حالت iptables و ipvs برابر 'all' و در حالت nftables برابر 'primary' است.
oomScoreAdj [Required]
int32

oomScoreAdj مقدار oom-score-adj برای فرایند kube-proxy است. مقادیر باید در بازه‌ی [-1000, 1000] باشند.
conntrack [Required]
KubeProxyConntrackConfiguration

conntrack شامل گزینه‌های پیکربندی مرتبط با conntrack است.
configSyncPeriod [Required]
meta/v1.Duration

configSyncPeriod مشخص می‌کند پیکربندی دریافتی از apiserver هر چند وقت یک‌بار تازه‌سازی شود. باید بزرگ‌تر از 0 باشد.
portRange [Required]
string

portRange پیش‌تر برای پیکربندی پراکسی userspace به کار می‌رفت، اما اکنون استفاده نمی‌شود.

bool

windowsRunAsService در صورت true بودن، یکپارچگی با API مدیر کنترل سرویس ویندوز (Windows service control manager) را فعال می‌کند.

bool

udpTimeout [Required]
meta/v1.Duration

udpStreamTimeout [Required]
meta/v1.Duration

udpStreamTimeout مشخص می‌کند یک ورودی conntrack بیکار UDP در وضعیت ASSURED تا چه مدت در جدول conntrack باقی بماند (برای مثال '300s'). برای تنظیم، باید بزرگ‌تر از 0 باشد.

KubeProxyIPTablesConfiguration {#kubeproxy-config-k8s-io-v1alpha1-KubeProxyIPTablesConfiguration}

KubeProxyIPTablesConfiguration شامل جزئیات پیکربندی مرتبط با iptables برای سرور پراکسی کوبرنتیز است.

FieldDescription
masqueradeBit [Required]
int32

masqueradeBit بیتی از فضای fwmark در iptables است که در صورت استفاده از حالت پراکسی iptables یا ipvs برای SNAT به کار می‌رود. مقادیر باید در بازه‌ی [0, 31] باشند.
masqueradeAll [Required]
bool

masqueradeAll به kube-proxy می‌گوید در هنگام استفاده از حالت پراکسی iptables یا ipvs، بر روی همه‌ی ترافیک ارسالی به IPهای cluster سرویس‌ها SNAT انجام دهد. این کار ممکن است با برخی افزونه‌های CNI لازم باشد.
localhostNodePorts [Required]
bool

localhostNodePorts در صورت false بودن، به kube-proxy می‌گوید رفتار قدیمی اجازه‌ی دسترسی به سرویس‌های NodePort از طریق localhost را غیرفعال کند. (فقط در حالت iptables و برای IPv4 اعمال می‌شود؛ NodePortهای localhost در حالت‌های پراکسی دیگر یا با IPv6 هرگز مجاز نیستند.)
syncPeriod [Required]
meta/v1.Duration

syncPeriod بازه‌ای است (برای مثال '5s'، '1m'، '2h22m') که مشخص می‌کند عملیات‌های مختلف همگام‌سازی مجدد و پاک‌سازی هر چند وقت یک‌بار انجام شوند. باید بزرگ‌تر از 0 باشد.
minSyncPeriod [Required]
meta/v1.Duration

minSyncPeriod کمینه‌ی فاصله‌ی زمانی بین همگام‌سازی‌های مجدد قوانین iptables است (برای مثال '5s'، '1m'، '2h22m'). مقدار 0 یعنی هر تغییر در Service یا EndpointSlice به همگام‌سازی مجدد فوری iptables منجر می‌شود.

ProxyMode {#kubeproxy-config-k8s-io-v1alpha1-ProxyMode}

(نام مستعار برای string)

ظاهر شده در:

  • KubeProxyConfiguration

ProxyMode حالت‌هایی را نشان می‌دهد که سرور پروکسی کوبرنتیز از آن‌ها استفاده می‌کند.

در پلتفرم‌های Linux سه حالت پروکسی در دسترس است: iptables، ipvs و nftables. در پلتفرم‌های Windows یک حالت پروکسی در دسترس است: kernelspace.

اگر حالت پروکسی مشخص نشود، یک حالت پروکسی پیش‌فرض استفاده خواهد شد (در حال حاضر این حالت در Linux برابر iptables و در Windows برابر kernelspace است). اگر حالت پروکسی انتخاب‌شده قابل استفاده نباشد (به دلیل نبود پشتیبانی هسته، نبود مؤلفه‌های فضای کاربر و غیره)، kube-proxy با یک خطا خارج می‌شود.
