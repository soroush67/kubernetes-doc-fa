AuthInfo شامل اطلاعاتی است که هویت را توصیف می‌کند. از این آبجکت برای اعلام هویت شما به کلاستر کوبرنتیز استفاده می‌شود.

string

ClientCertificate مسیر فایل گواهی کلاینت برای TLS است.
client-certificate-data
[]byte

ClientCertificateData شامل داده‌های رمزگذاری‌شده با PEM از یک فایل گواهی کلاینت برای TLS است. این مقدار بر ClientCertificate اولویت دارد.

string

ClientKeyData شامل داده‌های رمزگذاری‌شده با PEM از یک فایل کلید کلاینت برای TLS است. این مقدار بر ClientKey اولویت دارد.
token
string

Token توکن حامل (bearer token) برای احراز هویت در کلاستر کوبرنتیز است.
tokenFile
string

TokenFile اشاره‌گری به فایلی است که شامل یک توکن حامل (مطابق توضیح بالا) است. اگر هم Token و هم TokenFile موجود باشند، TokenFile به‌طور دوره‌ای خوانده می‌شود و آخرین مقداری که با موفقیت خوانده شده باشد بر Token اولویت دارد.

Cluster {#Cluster}

Appears in:

  • NamedCluster

Cluster شامل اطلاعاتی درباره نحوه ارتباط با یک کلاستر کوبرنتیز است.

FieldDescription
server [Required]
string

Server آدرس کلاستر کوبرنتیز است (https://hostname:port).
tls-server-name
string

TLSServerName برای بررسی گواهی سرور استفاده می‌شود. اگر TLSServerName خالی باشد، از نام میزبانی که برای ارتباط با سرور استفاده شده است، استفاده می‌شود.
insecure-skip-tls-verify
bool

InsecureSkipTLSVerify بررسی اعتبار گواهی سرور را نادیده می‌گیرد. این کار اتصال‌های HTTPS شما را ناامن می‌کند.
certificate-authority
string

CertificateAuthority مسیر فایل گواهی مربوط به مرجع صدور گواهی (certificate authority) است.
certificate-authority-data
[]byte

CertificateAuthorityData شامل گواهی‌های مرجع صدور گواهی با رمزگذاری PEM است. این مقدار بر CertificateAuthority اولویت دارد.
proxy-url
string

ProxyURL نشانی URL پروکسی‌ای است که برای تمام درخواست‌های ارسال‌شده توسط این کلاینت استفاده می‌شود. نشانی‌های URL با طرح‌های "http"، "https" و "socks5" پشتیبانی می‌شوند. اگر این پیکربندی ارائه نشود یا رشته خالی باشد، کلاینت تلاش می‌کند پیکربندی پروکسی را از متغیرهای محیطی http_proxy و https_proxy بسازد. اگر این متغیرهای محیطی تنظیم نشده باشند، کلاینت برای درخواست‌ها از پروکسی استفاده نمی‌کند.

پروکسی socks5 در حال حاضر از نقاط پایانی استریمینگ spdy (exec، attach، port forward) پشتیبانی نمی‌کند.
disable-compression
bool

DisableCompression به کلاینت اجازه می‌دهد از فشرده‌سازی پاسخ برای تمام درخواست‌ها به سرور صرف‌نظر کند. این گزینه زمانی که پهنای باند شبکه میان کلاینت و سرور فراوان است، با صرفه‌جویی در زمان فشرده‌سازی (سمت سرور) و بازگشایی فشرده‌سازی (سمت کلاینت) برای تسریع درخواست‌ها (به‌ویژه درخواست‌های list) مفید است: https://github.com/kubernetes/kubernetes/issues/112296.
extensions
[]NamedExtension

Extensions اطلاعات اضافی را نگه می‌دارد. این فیلد برای توسعه‌دهندگان افزونه مفید است تا عملیات خواندن و نوشتن فیلدهای ناشناخته را بازنویسی نکند.

ExecConfig {#ExecConfig}

Appears in:

  • AuthInfo

ExecConfig دستوری را برای ارائه اعتبارنامه‌های کلاینت مشخص می‌کند. این دستور اجرا می‌شود و خروجی ساختاریافته‌ای شامل اعتبارنامه‌ها را در stdout تولید می‌کند.

برای مشخصات دقیق قالب ورودی و خروجی، به گروه API با نام client.authentication.k8s.io مراجعه کنید.

FieldDescription
command [Required]
string

دستوری که باید اجرا شود.
args
[]string

آرگومان‌هایی که هنگام اجرای دستور به آن ارسال می‌شوند.
env
[]ExecEnvVar

Env متغیرهای محیطی اضافی را که باید در اختیار فرایند قرار گیرند تعریف می‌کند. این‌ها با محیط میزبان و همچنین متغیرهایی که client-go برای ارسال آرگومان به افزونه استفاده می‌کند، ترکیب (union) می‌شوند.
apiVersion [Required]
string

نسخه ورودی ترجیحی ExecInfo. ExecCredentials بازگردانده‌شده باید از همان نسخه رمزگذاری ورودی استفاده کند.
installHint [Required]
string

این متن زمانی به کاربر نمایش داده می‌شود که فایل اجرایی به نظر موجود نباشد. برای مثال، brew install foo-cli می‌تواند InstallHint مناسبی برای foo-cli در سیستم‌های Mac OS باشد.
provideClusterInfo [Required]
bool

ProvideClusterInfo تعیین می‌کند که آیا اطلاعات کلاستر، که ممکن است شامل داده‌های بسیار بزرگ CA باشد، به‌عنوان بخشی از متغیر محیطی KUBERNETES_EXEC_INFO به این افزونه exec ارائه شود یا خیر. به‌طور پیش‌فرض روی false تنظیم شده است. بسته k8s.io/client-go/tools/auth/exec متدهای کمکی برای خواندن این متغیر محیطی فراهم می‌کند.
interactiveMode
ExecInteractiveMode

InteractiveMode رابطه این افزونه با ورودی استاندارد را تعیین می‌کند. مقادیر معتبر عبارت‌اند از "Never" (این افزونه exec هرگز از ورودی استاندارد استفاده نمی‌کند)، "IfAvailable" (این افزونه exec در صورت در دسترس بودن ورودی استاندارد می‌خواهد از آن استفاده کند) یا "Always" (این افزونه exec برای کارکرد به ورودی استاندارد نیاز دارد). برای جزئیات بیشتر، مقادیر ExecInteractiveMode را ببینید.

اگر APIVersion برابر client.authentication.k8s.io/v1alpha1 یا client.authentication.k8s.io/v1beta1 باشد، این فیلد اختیاری است و در صورت تنظیم‌نشدن، مقدار پیش‌فرض آن "IfAvailable" است. در غیر این صورت، این فیلد الزامی است.
