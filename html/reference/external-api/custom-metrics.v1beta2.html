Kubernetes Custom Metrics (v1beta2)

بسته v1beta2 نسخه v1beta2 از API مربوط به custom_metrics است.

انواع منابع

MetricListOptions {#custom-metrics-k8s-io-v1beta2-MetricListOptions}

MetricListOptions برای انتخاب متریک‌ها بر اساس انتخابگرهای برچسب آن‌ها استفاده می‌شود.

فیلدتوضیحات
apiVersion
string		custom.metrics.k8s.io/v1beta2
kind
string		MetricListOptions
labelSelector
string

یک انتخابگر (selector) برای محدود کردن فهرست آبجکت‌های بازگردانده‌شده بر اساس برچسب‌های آن‌ها. مقدار پیش‌فرض، همه‌چیز است.
metricLabelSelector
string

یک انتخابگر (selector) برای محدود کردن فهرست متریک‌های بازگردانده‌شده بر اساس برچسب‌های آن‌ها

MetricValue {#custom-metrics-k8s-io-v1beta2-MetricValue}

ظاهر می‌شود در:

  • MetricValueList

MetricValue مقدار متریک برای یک آبجکت است.

فیلدتوضیحات
apiVersion
string		custom.metrics.k8s.io/v1beta2
kind
string		MetricValue
describedObject [Required]
core/v1.ObjectReference

ارجاعی به آبجکت توصیف‌شده
metric [Required]
MetricIdentifier 		توضیحی ارائه نشده است.
timestamp [Required]
meta/v1.Time

زمانی را که متریک‌ها در آن تولید شده‌اند نشان می‌دهد.
windowSeconds [Required]
int64

پنجره زمانی ([Timestamp-Window, Timestamp]) را نشان می‌دهد که این متریک‌ها از آن محاسبه شده‌اند؛ این مقدار هنگام بازگرداندن متریک‌های نرخ (rate) که از متریک‌های تجمعی محاسبه شده‌اند تعیین می‌شود (و برای متریک‌های لحظه‌ای غیرمحاسبه‌شده صفر است).
value [Required]
k8s.io/apimachinery/pkg/api/resource.Quantity

مقدار متریک برای این آبجکت

MetricValueList فهرستی از مقادیر یک متریک مشخص برای مجموعه‌ای از آبجکت‌هاست.

items [Required]

MetricIdentifier {#custom-metrics-k8s-io-v1beta2-MetricIdentifier}

ظاهر می‌شود در:

  • MetricValue

MetricIdentifier یک متریک را با نام و در صورت نیاز با انتخابگر (selector) شناسایی می‌کند.

فیلدتوضیحات
name [Required]
string

name نام متریک مورد نظر است.
selector
meta/v1.LabelSelector

selector نشان‌دهنده انتخابگر برچسبی است که می‌توان از آن برای انتخاب این متریک استفاده کرد و معمولاً همان انتخابگری است که در پرس‌وجوی مورد استفاده برای دریافت این متریک ارسال شده است. اگر این فیلد خالی بماند، برای جمع‌آوری متریک‌ها فقط نام (Name) متریک استفاده می‌شود.
