NodeMetrics {#metrics-k8s-io-v1beta1-NodeMetrics}

در این موارد ظاهر می‌شود:

  • NodeMetricsList

NodeMetrics متریک‌های میزان استفاده از منابع یک نود را مشخص می‌کند.

فیلدتوضیحات
apiVersion
string		metrics.k8s.io/v1beta1
kind
string		NodeMetrics
metadata
meta/v1.ObjectMeta

فراداده استاندارد آبجکت. اطلاعات بیشتر: https://git.k8s.io/community/contributors/devel/sig-architecture/api-conventions.md#metadata

برای مشاهده فیلدهای metadata به مستندات API کوبرنتیز مراجعه کنید.
timestamp [الزامی]
meta/v1.Time

فیلدهای زیر بازه زمانی‌ای را تعریف می‌کنند که متریک‌ها از آن گردآوری شده‌اند؛ این بازه برابر است با [Timestamp-Window, Timestamp].
window [الزامی]
meta/v1.Duration 		توضیحی ارائه نشده است.
usage [الزامی]
core/v1.ResourceList

میزان استفاده از حافظه برابر با مجموعه کاری حافظه (memory working set) است.
