کتابخانه‌های کلاینت

این صفحه مروری بر کتابخانه‌های کلاینت (client libraries) ارائه می‌دهد که برای استفاده از API کوبرنتیز در زبان‌های برنامه‌نویسی گوناگون در دسترس هستند.

برای نوشتن برنامه‌هایی که از REST API کوبرنتیز استفاده می‌کنند، لازم نیست فراخوانی‌های API و انواع درخواست و پاسخ را خودتان پیاده‌سازی کنید. می‌توانید از یک کتابخانهٔ کلاینت برای زبان برنامه‌نویسی موردنظرتان استفاده کنید.

کتابخانه‌های کلاینت معمولاً کارهای رایجی مانند احراز هویت را برای شما انجام می‌دهند. اگر کلاینت API درون کلاستر کوبرنتیز اجرا شود، بیشتر کتابخانه‌های کلاینت می‌توانند Service Account کوبرنتیز را شناسایی کنند و از آن برای احراز هویت بهره بگیرند. همچنین می‌توانند قالب فایل kubeconfig را تفسیر کنند تا اعتبارنامه‌ها و نشانی API Server را از آن بخوانند.
