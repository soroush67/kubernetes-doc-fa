APIResource

APIResource نام یک منبع و namespaced بودن یا نبودن آن را مشخص می‌کند.

apiVersion: meta/v1

import "k8s.io/apimachinery/pkg/apis/meta/v1"

APIResource {#APIResource}

APIResource نام یک منبع و namespaced بودن یا نبودن آن را مشخص می‌کند.

FieldDescription
categories
string array		 categories فهرستی از منابع گروه‌بندی‌شده است که این منبع به آن‌ها تعلق دارد (برای مثال 'all').
group
string		 group گروه ترجیحی منبع است. مقدار خالی به این معناست که گروه همان گروهِ فهرست منابعِ حاوی آن است. برای زیرمنبع‌ها (subresource) ممکن است این مقدار متفاوت باشد، برای مثال: Scale".
kind *
string		 kind نوع (kind) منبع را مشخص می‌کند (برای مثال 'Foo' نوعِ منبع 'foo' است).
name *
string		 name نام جمع منبع است.
namespaced *
boolean		 namespaced نشان می‌دهد که منبع در فضای نام (namespace) قرار می‌گیرد یا خیر.
shortNames
string array		 shortNames فهرستی از نام‌های کوتاهِ پیشنهادی برای منبع است.
singularName *
string		 singularName نام مفرد منبع است. این فیلد به کلاینت‌ها امکان می‌دهد نام جمع و مفرد را به‌صورت مبهم (opaque) مدیریت کنند. singularName برای گزارش وضعیت یک آیتم واحد مناسب‌تر است و در رابط خط فرمان kubectl هر دو شکل مفرد و جمع مجاز هستند.
storageVersionHash
string		 مقدار hash نسخه ذخیره‌سازی (storage version) است؛ یعنی نسخه‌ای که این منبع هنگام نوشتن در data store به آن تبدیل می‌شود. کلاینت‌ها باید این مقدار را مبهم (opaque) در نظر بگیرند و فقط مقایسه برابری روی آن معتبر است. این قابلیت آلفا است و ممکن است در آینده تغییر کند یا حذف شود. apiserver این فیلد را تنها در صورتی مقداردهی می‌کند که feature gate با نام StorageVersionHash فعال باشد. این فیلد حتی پس از ارتقا به مرحله‌های بعدی نیز اختیاری باقی می‌ماند.
verbs *
string array		 verbs فهرستی از افعال (verb) پشتیبانی‌شده در kube است (شامل get، list، watch، create، update، patch، delete، deletecollection و proxy).
version
string		 version نسخه ترجیحی منبع است. مقدار خالی به این معناست که نسخه همان نسخهٔ فهرست منابعِ حاوی آن است. برای زیرمنبع‌ها ممکن است این مقدار متفاوت باشد، برای مثال: v1 (در حالی که درون نسخه v1beta1 از گروه منبع هسته قرار دارد)".

APIResourceList {#APIResourceList}

APIResourceList فهرستی از APIResource است که برای نمایش نام منابع پشتیبانی‌شده در یک گروه و نسخهٔ مشخص و نیز namespaced بودن یا نبودن منبع استفاده می‌شود.

FieldDescription
apiVersion
string		 APIVersion طرحواره نسخه‌دار این نمایش از یک آبجکت را تعریف می‌کند. سرورها باید طرحواره‌های شناخته‌شده را به آخرین مقدار داخلی تبدیل کنند و می‌توانند مقادیر ناشناخته را رد کنند. اطلاعات بیشتر: https://git.k8s.io/community/contributors/devel/sig-architecture/api-conventions.md#resources
groupVersion *
string		 groupVersion گروه و نسخه‌ای است که این APIResourceList برای آن است.
kind
string		 Kind رشته‌ای است که منبع REST مربوط به این آبجکت را مشخص می‌کند. سرورها ممکن است این مقدار را از نقطه پایانی (endpoint) که کلاینت درخواست‌ها را به آن ارسال می‌کند استنباط کنند. این فیلد قابل به‌روزرسانی نیست و باید به‌صورت CamelCase باشد. اطلاعات بیشتر: https://git.k8s.io/community/contributors/devel/sig-architecture/api-conventions.md#types-kinds
resources *
APIResource array		 resources شامل نام منابع و namespaced بودن یا نبودن آن‌هاست.
