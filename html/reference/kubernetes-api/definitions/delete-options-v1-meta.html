فیلدتوضیحات
apiVersion
string		 APIVersion طرح‌واره نسخه‌دار (versioned schema) این نمایش از یک آبجکت را تعریف می‌کند. سرورها باید طرح‌واره‌های شناخته‌شده را به آخرین مقدار داخلی تبدیل کنند و ممکن است مقادیر ناشناخته را رد کنند. اطلاعات بیشتر: https://git.k8s.io/community/contributors/devel/sig-architecture/api-conventions.md#resources
dryRun
string array		 در صورت وجود، نشان می‌دهد که تغییرات نباید ماندگار شوند. مقدار نامعتبر یا ناشناخته برای دستور dryRun به پاسخ خطا منجر می‌شود و پردازش بیشتر درخواست انجام نخواهد شد. مقادیر معتبر عبارتند از: - All: همه مراحل dry run پردازش خواهند شد
gracePeriodSeconds
integer		 مدت زمان بر حسب ثانیه، پیش از آنکه آبجکت حذف شود. مقدار باید یک عدد صحیح نامنفی باشد. مقدار صفر به معنای حذف فوری است. اگر این مقدار nil باشد، از دوره مهلت پیش‌فرض نوع مشخص‌شده استفاده می‌شود. در صورت مشخص نشدن، به‌طور پیش‌فرض مقداری مختص هر آبجکت به کار می‌رود. مقدار صفر به معنای حذف فوری است.
ignoreStoreReadErrorWithClusterBreakingPotential
boolean		 اگر روی true تنظیم شود، در صورتی که جریان عادی حذف با خطای آبجکت خراب‌شده (corrupt) شکست بخورد، حذف ناایمن منبع را فعال می‌کند. یک منبع در صورتی خراب در نظر گرفته می‌شود که به دلیل الف) غیرممکن بودن تبدیل داده‌های آن، مثلاً شکست در رمزگشایی، یا ب) ناموفق بودن رمزگشایی آن به یک آبجکت، نتوان آن را با موفقیت از ذخیره‌سازی زیرین بازیابی کرد. توجه: حذف ناایمن محدودیت‌های finalizer را نادیده می‌گیرد، بررسی‌های پیش‌شرط را رد می‌کند و آبجکت را از ذخیره‌سازی حذف می‌کند. هشدار: اگر بار کاری مرتبط با منبعی که به‌صورت ناایمن حذف می‌شود به جریان عادی حذف وابسته باشد، این کار ممکن است کلاستر را دچار اختلال کند. فقط زمانی از آن استفاده کنید که واقعاً بدانید چه می‌کنید. مقدار پیش‌فرض false است و کاربر باید برای فعال‌سازی آن صراحتاً آن را انتخاب کند
kind
string		 Kind یک مقدار رشته‌ای است که منبع REST را نشان می‌دهد که این آبجکت نمایانگر آن است. سرورها ممکن است آن را از نقطه انتهایی (endpoint) که کلاینت درخواست‌ها را به آن ارسال می‌کند استنتاج کنند. قابل به‌روزرسانی نیست. به‌صورت CamelCase است. اطلاعات بیشتر: https://git.k8s.io/community/contributors/devel/sig-architecture/api-conventions.md#types-kinds
orphanDependents
boolean		 منسوخ‌شده: لطفاً از PropagationPolicy استفاده کنید؛ این فیلد در نسخه 1.7 منسوخ خواهد شد. مشخص می‌کند که آیا آبجکت‌های وابسته باید یتیم (orphan) شوند یا خیر. اگر true یا false باشد، finalizer با نام "orphan" به فهرست finalizerهای آبجکت اضافه یا از آن حذف می‌شود. فقط یکی از این فیلد یا PropagationPolicy را می‌توان تنظیم کرد، نه هر دو را.
preconditions
Preconditions		 پیش از انجام حذف باید برآورده شوند. در صورت امکان‌پذیر نبودن، وضعیت 409 Conflict بازگردانده می‌شود.
propagationPolicy
string		 مشخص می‌کند که آیا و چگونه garbage collection انجام شود. فقط یکی از این فیلد یا OrphanDependents را می‌توان تنظیم کرد، نه هر دو را. سیاست پیش‌فرض بر اساس finalizerهای موجود در metadata.finalizers و سیاست پیش‌فرض مختص منبع تعیین می‌شود. مقادیر قابل قبول عبارتند از: 'Orphan' - وابسته‌ها را یتیم می‌کند؛ 'Background' - به garbage collector اجازه می‌دهد وابسته‌ها را در پس‌زمینه حذف کند؛ 'Foreground' - یک سیاست آبشاری (cascading) است که همه وابسته‌ها را در پیش‌زمینه حذف می‌کند.
