آزمون انطباق نود

آزمون انطباق نود (Node conformance test) یک چارچوب آزمون کانتینری‌شده است که برای هر نود، راستی‌آزمایی سیستم و آزمون عملکرد فراهم می‌کند. این آزمون بررسی می‌کند که آیا نود حداقل الزامات کوبرنتیز را برآورده می‌کند یا نه؛ نودی که این آزمون را با موفقیت بگذراند، صلاحیت پیوستن به یک کلاستر کوبرنتیز را دارد.

پیش‌نیازهای نود

برای اجرای آزمون انطباق نود، نود باید همان پیش‌نیازهای یک نود استاندارد کوبرنتیز را داشته باشد. دست‌کم دیمن‌های (daemon) زیر باید روی نود نصب باشند:

  • محیط‌های اجرای کانتینر سازگار با CRI، مانند Docker، containerd و CRI-O
  • kubelet

اجرای آزمون انطباق نود

برای اجرای آزمون انطباق نود، مراحل زیر را انجام دهید:

  1. مقدار گزینهٔ --kubeconfig را برای kubelet مشخص کنید؛ برای مثال: --kubeconfig=/var/lib/kubelet/config.yaml. از آنجا که چارچوب آزمون برای آزمودن kubelet یک control plane محلی راه‌اندازی می‌کند، از http://localhost:8080 به‌عنوان نشانی سرور API استفاده کنید. چند پارامتر خط فرمان دیگر نیز برای kubelet وجود دارد که ممکن است بخواهید از آن‌ها استفاده کنید:

    • --cloud-provider: اگر از --cloud-provider=gce استفاده می‌کنید، برای اجرای آزمون باید این فلگ را حذف کنید.

  2. آزمون انطباق نود را با فرمان زیر اجرا کنید:

    # $CONFIG_DIR is the pod manifest path of your kubelet.
# $LOG_DIR is the test output path.
sudo docker run -it --rm --privileged --net=host \
  -v /:/rootfs -v $CONFIG_DIR:$CONFIG_DIR -v $LOG_DIR:/var/result \
  registry.k8s.io/node-test:0.2

اجرای آزمون انطباق نود برای معماری‌های دیگر

کوبرنتیز ایمیج‌های داکر آزمون انطباق نود را برای معماری‌های دیگر نیز فراهم می‌کند:

معماری ایمیج
amd64 node-test-amd64
arm node-test-arm
arm64 node-test-arm64

اجرای آزمون‌های انتخابی

برای اجرای آزمون‌های مشخص، مقدار متغیر محیطی FOCUS را با عبارت باقاعدهٔ (regular expression) آزمون‌هایی که می‌خواهید اجرا شوند جایگزین کنید.

sudo docker run -it --rm --privileged --net=host \
  -v /:/rootfs:ro -v $CONFIG_DIR:$CONFIG_DIR -v $LOG_DIR:/var/result \
  -e FOCUS=MirrorPod \ # Only run MirrorPod test
  registry.k8s.io/node-test:0.2

برای رد کردن آزمون‌های مشخص، مقدار متغیر محیطی SKIP را با عبارت باقاعدهٔ آزمون‌هایی که می‌خواهید اجرا نشوند جایگزین کنید.

sudo docker run -it --rm --privileged --net=host \
  -v /:/rootfs:ro -v $CONFIG_DIR:$CONFIG_DIR -v $LOG_DIR:/var/result \
  -e SKIP=MirrorPod \ # Run all conformance tests but skip MirrorPod test
  registry.k8s.io/node-test:0.2

آزمون انطباق نود نسخهٔ کانتینری‌شدهٔ آزمون e2e نود است. این آزمون به‌طور پیش‌فرض همهٔ آزمون‌های انطباق را اجرا می‌کند.

در اصل، اگر کانتینر را به‌درستی پیکربندی کنید و حجم‌های (volume) لازم را به‌درستی mount کنید، می‌توانید هر آزمون e2e نود را اجرا کنید. اما اکیداً توصیه می‌شود که فقط آزمون‌های انطباق را اجرا کنید، زیرا اجرای آزمون‌های غیرانطباقی به پیکربندی بسیار پیچیده‌تری نیاز دارد.

نکات و محدودیت‌ها

  • این آزمون تعدادی ایمیج داکر را روی نود باقی می‌گذارد؛ از جمله ایمیج آزمون انطباق نود و ایمیج‌های کانتینرهایی که در آزمون عملکرد به کار رفته‌اند.
  • این آزمون کانتینرهای متوقف‌شده را روی نود باقی می‌گذارد. این کانتینرها در طول آزمون عملکرد ایجاد می‌شوند.
