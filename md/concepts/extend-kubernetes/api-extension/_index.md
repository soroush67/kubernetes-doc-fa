title: گسترش API کوبرنتیز
weight: 30

منابع سفارشی (custom resources) افزونه‌هایی بر API کوبرنتیز هستند. کوبرنتیز دو روش برای افزودن منابع سفارشی به کلاستر شما فراهم می‌کند:

- با سازوکار [CustomResourceDefinition](/docs/concepts/extend-kubernetes/api-extension/custom-resources/)
  (CRD) می‌توانید یک API سفارشی جدید را با گروه API، نوع (kind) و طرح‌واره (schema) دلخواه خود
  به‌صورت اعلانی تعریف کنید.
  در این روش، control plane کوبرنتیز منبع سفارشی شما را ارائه می‌دهد و ذخیره‌سازی آن را نیز بر عهده می‌گیرد.
  به کمک CRDها می‌توانید بدون نوشتن و اجرای یک سرور API سفارشی، انواع جدیدی از منابع را برای کلاستر خود ایجاد کنید.
- [لایه تجمیع](/docs/concepts/extend-kubernetes/api-extension/apiserver-aggregation/)
  پشت سرور API اصلی قرار می‌گیرد و سرور API اصلی نقش پراکسی را ایفا می‌کند.
  به این چیدمان، تجمیع API (API Aggregation یا AA) گفته می‌شود. با این روش می‌توانید
  با نوشتن و استقرار سرور API خودتان، پیاده‌سازی‌های تخصصی برای منابع سفارشی خود فراهم کنید.
  سرور API اصلی درخواست‌های مربوط به APIهای سفارشی‌ای را که مشخص کرده‌اید به سرور API شما واگذار می‌کند
  و به این ترتیب، این APIها در دسترس همه کلاینت‌های آن قرار می‌گیرند.
