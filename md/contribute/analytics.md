این صفحه حاوی اطلاعاتی درباره‌ی داشبورد تحلیل‌های kubernetes.io است.


<!-- body -->

[مشاهده‌ی داشبورد](https://lookerstudio.google.com/u/0/reporting/fe615dc5-59b0-4db5-8504-ef9eacb663a9/page/4VDGB/).

این داشبورد با استفاده از [Google Looker Studio](https://lookerstudio.google.com/overview) ساخته شده است و اطلاعاتی را نشان می‌دهد که از اوت ۲۰۲۲ با استفاده از Google Analytics 4 در kubernetes.io گردآوری شده است.

### استفاده از داشبورد

به‌طور پیش‌فرض، داشبورد همه‌ی داده‌های تحلیلی گردآوری‌شده در ۳۰ روز گذشته را نشان می‌دهد. برای مشاهده‌ی داده‌های یک بازه‌ی زمانی دیگر از انتخابگر تاریخ استفاده کنید. سایر گزینه‌های فیلتر به شما امکان می‌دهند داده‌ها را بر اساس موقعیت کاربر، دستگاهی که برای دسترسی به سایت استفاده شده، ترجمه‌ی مورد استفاده از مستندات و موارد دیگر مشاهده کنید.

 اگر مشکلی در این داشبورد مشاهده کردید یا می‌خواهید بهبودی را درخواست کنید، لطفاً [یک issue باز کنید](https://github.com/kubernetes/website/issues/new/choose).
