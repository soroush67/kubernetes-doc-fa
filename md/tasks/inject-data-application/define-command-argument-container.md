## تعریف دستور و آرگومان‌ها هنگام ایجاد یک Pod

هنگام ایجاد یک Pod، می‌توانید برای کانتینرهایی که در آن Pod اجرا می‌شوند یک دستور (command) و آرگومان‌هایی (arguments) تعریف کنید. برای تعریف دستور، فیلد `command` را در فایل پیکربندی قرار دهید. برای تعریف آرگومان‌های دستور، فیلد `args` را در فایل پیکربندی قرار دهید. پس از ایجاد Pod، دستور و آرگومان‌هایی که تعریف کرده‌اید قابل تغییر نیستند.

دستور و آرگومان‌هایی که در فایل پیکربندی تعریف می‌کنید، دستور و آرگومان‌های پیش‌فرضی را که ایمیج کانتینر فراهم می‌کند بازنویسی می‌کنند. اگر آرگومان‌ها را تعریف کنید اما دستوری تعریف نکنید، دستور پیش‌فرض همراه با آرگومان‌های جدید شما اجرا می‌شود.

{{< note >}}
در برخی از محیط‌های اجرای کانتینر، فیلد `command` معادل `ENTRYPOINT` و فیلد `args` معادل `CMD` است.
{{< /note >}}

در این تمرین، یک Pod ایجاد می‌کنید که یک کانتینر را اجرا می‌کند. فایل پیکربندی این Pod یک دستور و دو آرگومان تعریف می‌کند:

{{% code_sample file="pods/commands.yaml" %}}

1. یک Pod بر اساس فایل پیکربندی YAML ایجاد کنید:

   ```shell
   kubectl apply -f https://k8s.io/examples/pods/commands.yaml
   ```

1. فهرست Podهای در حال اجرا را مشاهده کنید:

   ```shell
   kubectl get pods
   ```

   خروجی نشان می‌دهد که اجرای کانتینرِ درون Pod با نام command-demo به پایان رسیده است.

1. برای دیدن خروجی دستوری که در کانتینر اجرا شد، لاگ‌های Pod را مشاهده کنید:

   ```shell
   kubectl logs command-demo
   ```

   خروجی، مقادیر متغیرهای محیطی HOSTNAME و KUBERNETES_PORT را نشان می‌دهد:

   ```
   command-demo
   tcp://10.3.240.1:443
   ```

## استفاده از متغیرهای محیطی برای تعریف آرگومان‌ها

در مثال قبل، آرگومان‌ها را مستقیماً با ارائهٔ رشته‌ها تعریف کردید. به‌جای ارائهٔ مستقیم رشته‌ها، می‌توانید آرگومان‌ها را با استفاده از متغیرهای محیطی نیز تعریف کنید:

```yaml
env:
- name: MESSAGE
  value: "hello world"
command: ["/bin/echo"]
args: ["$(MESSAGE)"]
```

بنابراین می‌توانید آرگومان یک Pod را با هر یک از روش‌هایی که برای تعریف متغیرهای محیطی در دسترس است تعریف کنید؛ از جمله [ConfigMapها](/docs/tasks/configure-pod-container/configure-pod-configmap/) و [Secretها](/docs/concepts/configuration/secret/).

{{< note >}}
متغیر محیطی درون پرانتز و به شکل `"$(VAR)"` نوشته می‌شود. این کار برای جایگذاری مقدار متغیر در فیلد `command` یا `args` ضروری است.
{{< /note >}}

## اجرای دستور در یک شل

در برخی موارد، لازم است دستور شما در یک شل (shell) اجرا شود. برای مثال، ممکن است دستور شما از چند دستور تشکیل شده باشد که با پایپ به هم متصل شده‌اند، یا ممکن است یک اسکریپت شل باشد. برای اجرای دستور در یک شل، آن را به این شکل بسته‌بندی کنید:

```shell
command: ["/bin/sh"]
args: ["-c", "while true; do echo hello; sleep 10;done"]
```
