<!-- overview -->
کوبرنتیز یک افزونهٔ (addon) DNS برای کلاستر ارائه می‌دهد که در بیشتر محیط‌های پشتیبانی‌شده به‌طور پیش‌فرض فعال است. در نسخهٔ ۱.۱۱ کوبرنتیز و نسخه‌های بعدی، استفاده از CoreDNS توصیه می‌شود و kubeadm آن را به‌طور پیش‌فرض نصب می‌کند.

<!-- body -->
برای اطلاعات بیشتر دربارهٔ نحوهٔ پیکربندی CoreDNS برای یک کلاستر کوبرنتیز، به [سفارشی‌سازی سرویس DNS](/docs/tasks/administer-cluster/dns-custom-nameservers/) مراجعه کنید.
