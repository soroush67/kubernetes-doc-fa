هنگامی که کوبرنتیز را در محیطی با مرزبندی‌های سخت‌گیرانه شبکه اجرا می‌کنید، مانند مرکز داده درون‌سازمانی (on-premises) با فایروال‌های فیزیکی شبکه یا شبکه‌های مجازی در ابر عمومی، بهتر است از پورت‌ها و پروتکل‌هایی که مؤلفه‌های کوبرنتیز استفاده می‌کنند آگاه باشید.

## اجزای control plane

| پروتکل | جهت | بازه پورت | هدف | استفاده‌کننده |
|----------|-----------|------------|-------------------------|---------------------------|
| TCP      | ورودی   | 6443       | سرور API کوبرنتیز   | همه                       |
| TCP      | ورودی   | 2379-2380  | API کلاینت سرور etcd  | kube-apiserver، etcd      |
| TCP      | ورودی   | 10250      | API مربوط به kubelet             | خود مؤلفه، control plane       |
| TCP      | ورودی   | 10259      | kube-scheduler          | خود مؤلفه                      |
| TCP      | ورودی   | 10257      | kube-controller-manager | خود مؤلفه                      |

با اینکه پورت‌های etcd در بخش control plane آمده‌اند، می‌توانید کلاستر etcd خود را به‌صورت خارجی یا روی پورت‌های سفارشی نیز میزبانی کنید.

## نود(های) کارگر {#node}

| پروتکل | جهت | بازه پورت  | هدف               | استفاده‌کننده                 |
|----------|-----------|-------------|-----------------------|-------------------------|
| TCP      | ورودی   | 10250       | API مربوط به kubelet           | خود مؤلفه، control plane     |
| TCP      | ورودی   | 10256       | kube-proxy            | خود مؤلفه، متعادل‌کننده‌های بار (load balancer)    |
| TCP      | ورودی   | 30000-32767 | Serviceهای NodePort†    | همه                     |
| UDP      | ورودی   | 30000-32767 | Serviceهای NodePort†    | همه                     |

† بازه پورت پیش‌فرض برای [Serviceهای NodePort](/docs/concepts/services-networking/service/).

همه شماره‌پورت‌های پیش‌فرض را می‌توان تغییر داد. اگر از پورت‌های سفارشی استفاده می‌کنید، باید به‌جای پورت‌های پیش‌فرض ذکرشده در اینجا، همان پورت‌ها را باز کنید.

یک نمونه رایج، پورت سرور API است که گاهی به 443 تغییر داده می‌شود. راه دیگر این است که پورت پیش‌فرض را بدون تغییر نگه دارید و سرور API را پشت یک متعادل‌کننده بار قرار دهید که به پورت 443 گوش می‌دهد و درخواست‌ها را به پورت پیش‌فرض سرور API هدایت می‌کند.
