یک API پیشین در کوبرنتیز که محدودیت‌های امنیتی را هنگام ایجاد و به‌روزرسانی {{< glossary_tooltip term_id="pod" >}} اعمال می‌کرد.

<!--more--> 

PodSecurityPolicy از نسخهٔ v1.21 کوبرنتیز منسوخ شد و در نسخهٔ v1.25 حذف گردید.
به‌عنوان جایگزین، از [Pod Security Admission](/docs/concepts/security/pod-security-admission/) یا یک افزونهٔ admission شخص ثالث استفاده کنید.
