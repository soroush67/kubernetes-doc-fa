 یک آبجکت API که برای ذخیره‌سازی داده‌های غیرمحرمانه به‌صورت جفت‌های کلید-مقدار به کار می‌رود.
{{< glossary_tooltip text="پادها" term_id="pod" >}} می‌توانند از ConfigMapها به‌عنوان
متغیرهای محیطی، آرگومان‌های خط فرمان یا فایل‌های پیکربندی در یک
{{< glossary_tooltip text="حجم" term_id="volume" >}} استفاده کنند.

<!--more--> 

با استفاده از ConfigMap می‌توانید پیکربندی‌های وابسته به محیط را از {{< glossary_tooltip text="ایمیج‌های کانتینر" term_id="image" >}} خود جدا کنید تا برنامه‌هایتان به‌آسانی قابل انتقال باشند.
