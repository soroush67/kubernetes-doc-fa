فناوری Docker (به‌طور مشخص، Docker Engine) یک فناوری نرم‌افزاری است که مجازی‌سازی در سطح سیستم‌عامل را فراهم می‌کند؛ این نوع مجازی‌سازی با نام {{< glossary_tooltip text="کانتینر" term_id="container" >}} نیز شناخته می‌شود.

<!--more-->

فناوری Docker از قابلیت‌های جداسازی منابع در هسته لینوکس، مانند cgroups و فضاهای نام هسته (kernel namespaces)، و نیز از یک سیستم فایل با قابلیت اجتماع (union-capable)، مانند OverlayFS و نمونه‌های دیگر، استفاده می‌کند. به این ترتیب، کانتینرهای مستقل می‌توانند درون یک نمونه واحد از لینوکس اجرا شوند و از سربار راه‌اندازی و نگهداری ماشین‌های مجازی (VMs) جلوگیری می‌شود.
