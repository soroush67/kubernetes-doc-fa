Docker (به‌طور مشخص، Docker Engine) یک فناوری نرم‌افزاری است که مجازی‌سازی در سطح سیستم‌عامل را فراهم می‌کند و با نام {{< glossary_tooltip text="کانتینر" term_id="container" >}} نیز شناخته می‌شود.

<!--more-->

Docker از ویژگی‌های جداسازی منابع در هسته لینوکس، مانند cgroups و namespaceهای هسته، و همچنین از یک سیستم فایل با قابلیت union مانند OverlayFS و موارد مشابه استفاده می‌کند تا کانتینرهای مستقل بتوانند درون یک نمونه واحد لینوکس اجرا شوند و از سربار راه‌اندازی و نگهداری ماشین‌های مجازی (VM) جلوگیری شود.
