مشخصات یک آبجکت API کوبرنتیز در قالب [JSON](https://www.json.org/json-en.html)
یا [YAML](https://yaml.org/).

<!--more-->
هر مانیفست وضعیت مطلوب یک آبجکت را مشخص می‌کند؛ کوبرنتیز پس از اعمال مانیفست، این وضعیت را حفظ می‌کند.
در قالب YAML، هر فایل می‌تواند چندین مانیفست داشته باشد.
