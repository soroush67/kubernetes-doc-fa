 خانواده‌ای از انواع API برای مدل‌سازی شبکه‌ی سرویس‌ها در کوبرنتیز.

<!--more--> 

Gateway API خانواده‌ای از انواع API توسعه‌پذیر، نقش‌محور و آگاه از پروتکل را برای مدل‌سازی شبکه‌ی سرویس‌ها در کوبرنتیز فراهم می‌کند.
