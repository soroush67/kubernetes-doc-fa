 فردی که کلاسترها را پیکربندی، کنترل و پایش می‌کند.

<!--more--> 

مسئولیت اصلی این فرد، فعال و در حال اجرا نگه داشتن کلاستر است. این کار ممکن است شامل فعالیت‌های نگهداری دوره‌ای یا ارتقاها باشد.<br>

{{< note >}}
اپراتورهای کلاستر با [الگوی Operator](/docs/concepts/extend-kubernetes/operator/) که API کوبرنتیز را گسترش می‌دهد، تفاوت دارند.
{{< /note >}}
