 شخصی که کلاسترها را پیکربندی، کنترل و پایش می‌کند.

<!--more--> 

مسئولیت اصلی او حفظ در دسترس بودن و عملکرد مداوم کلاستر است که ممکن است شامل فعالیت‌های نگهداری دوره‌ای یا ارتقاها باشد.<br>

{{< note >}}
اپراتورهای کلاستر با [الگوی Operator](/docs/concepts/extend-kubernetes/operator/) که API کوبرنتیز را گسترش می‌دهد، متفاوت هستند.
{{< /note >}}
