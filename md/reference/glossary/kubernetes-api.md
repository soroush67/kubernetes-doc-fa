 رابط برنامه‌نویسی مبتنی بر HTTP که به کاربران، مؤلفه‌های کلاستر و مؤلفه‌های خارجی امکان می‌دهد با یکدیگر ارتباط برقرار کنند و وضعیت آبجکت‌های کوبرنتیز را پرس‌وجو یا دستکاری کنند.

<!--more--> 

منابع کوبرنتیز و «رکوردهای نیت» (records of intent) همگی به‌صورت آبجکت‌های API ذخیره می‌شوند و از طریق فراخوانی‌های RESTful به API تغییر می‌یابند. API امکان می‌دهد پیکربندی به شیوه‌ای اعلانی (declarative) مدیریت شود. کاربران می‌توانند مستقیماً یا از طریق ابزارهایی مانند `kubectl` با Kubernetes API تعامل داشته باشند. API اصلی کوبرنتیز انعطاف‌پذیر است و می‌توان آن را گسترش داد تا از منابع سفارشی (custom resources) نیز پشتیبانی کند.
