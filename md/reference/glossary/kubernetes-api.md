 رابط HTTP که به کاربران، مؤلفه‌های کلاستر و مؤلفه‌های خارجی امکان می‌دهد با یکدیگر ارتباط برقرار کنند و وضعیت آبجکت‌های کوبرنتیز را جست‌وجو یا دست‌کاری کنند.

<!--more--> 

همهٔ منابع کوبرنتیز و «سوابق قصد» (records of intent) به‌صورت آبجکت‌های API ذخیره می‌شوند و با فراخوانی‌های RESTful به API تغییر می‌کنند. این API امکان مدیریت پیکربندی را به شیوه‌ای اعلانی (declarative) فراهم می‌کند. کاربران می‌توانند مستقیماً یا از طریق ابزارهایی مانند `kubectl` با API کوبرنتیز تعامل داشته باشند. هستهٔ API کوبرنتیز انعطاف‌پذیر است و می‌توان آن را برای پشتیبانی از منابع سفارشی نیز گسترش داد.
