 یک API افزونه‌ای سابق که به برنامه‌های در حال اجرا در کلاسترهای کوبرنتیز امکان می‌داد به‌سادگی از محصولات نرم‌افزاری مدیریت‌شدهٔ خارجی، مانند سرویس ذخیره‌سازی داده که یک ارائه‌دهندهٔ ابری عرضه می‌کند، استفاده کنند.

<!--more--> 

این API روشی برای فهرست‌کردن، آماده‌سازی (provision) و اتصال به {{< glossary_tooltip text="سرویس‌های مدیریت‌شده" term_id="managed-service" >}} خارجی فراهم می‌کرد، بدون آنکه نیازی به دانش دقیق دربارهٔ نحوهٔ ایجاد یا مدیریت آن سرویس‌ها باشد.
