 کاتالوگ سرویس یک API افزونه‌ای سابق بود که به برنامه‌های در حال اجرا در کلاسترهای کوبرنتیز امکان می‌داد به‌آسانی از نرم‌افزارهای مدیریت‌شده خارجی، مانند سرویس ذخیره‌سازی داده‌ای که یک ارائه‌دهنده ابری عرضه می‌کند، استفاده کنند.

<!--more--> 

این API روشی برای فهرست‌کردن، تأمین (provision) و اتصال (bind) به {{< glossary_tooltip text="سرویس‌های مدیریت‌شده" term_id="managed-service" >}} خارجی فراهم می‌کرد، بی‌آنکه به دانش دقیقی درباره نحوه ایجاد یا مدیریت این سرویس‌ها نیاز باشد.
