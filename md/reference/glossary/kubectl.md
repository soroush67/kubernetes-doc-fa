ابزار خط فرمانی که با استفاده از API کوبرنتیز با
{{< glossary_tooltip text="control plane" term_id="control-plane" >}}
یک کلاستر کوبرنتیز ارتباط برقرار می‌کند.

<!--more--> 

با ابزار `kubectl` می‌توانید آبجکت‌های کوبرنتیز را ایجاد، بررسی، به‌روزرسانی و حذف کنید.
