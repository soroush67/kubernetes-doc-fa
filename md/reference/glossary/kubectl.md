ابزار خط فرمان برای ارتباط با {{< glossary_tooltip text="control plane" term_id="control-plane" >}} یک کلاستر کوبرنتیز
از طریق API کوبرنتیز.

<!--more--> 

می‌توانید از `kubectl` برای ایجاد، بررسی، به‌روزرسانی و حذف آبجکت‌های کوبرنتیز استفاده کنید.

در زبان انگلیسی، `kubectl` (به‌طور رسمی) به صورت /kjuːb/ /kənˈtɹəʊl/ تلفظ می‌شود (مانند «cube control»).
