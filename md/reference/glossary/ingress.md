 یک آبجکت API که دسترسی خارجی به سرویس‌های درون کلاستر، معمولاً از نوع HTTP، را مدیریت می‌کند.

<!--more--> 

Ingress می‌تواند امکاناتی مانند توزیع بار (load balancing)، خاتمه‌دهی SSL (SSL termination) و میزبانی مجازی مبتنی بر نام (name-based virtual hosting) را فراهم کند.
