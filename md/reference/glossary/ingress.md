 یک آبجکت API که دسترسی بیرونی به سرویس‌های یک کلاستر را، معمولاً از طریق HTTP، مدیریت می‌کند.

<!--more--> 

هر Ingress می‌تواند توزیع بار (load balancing)، خاتمه‌دادن SSL (SSL termination) و میزبانی مجازی مبتنی بر نام (name-based virtual hosting) را فراهم کند.
