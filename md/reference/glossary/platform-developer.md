 فردی که پلتفرم کوبرنتیز را متناسب با نیازهای پروژه خود سفارشی‌سازی می‌کند.

<!--more--> 

یک توسعه‌دهنده پلتفرم می‌تواند، برای مثال، از [منابع سفارشی (Custom Resources)](/docs/concepts/extend-kubernetes/api-extension/custom-resources/) یا
[گسترش API کوبرنتیز با لایه تجمیع (aggregation layer)](/docs/concepts/extend-kubernetes/api-extension/apiserver-aggregation/)
استفاده کند تا قابلیت‌های جدیدی را، به‌طور ویژه برای برنامه خود، به نمونه کوبرنتیز خود اضافه کند.
برخی از توسعه‌دهندگان پلتفرم هم‌زمان {{< glossary_tooltip text="مشارکت‌کننده" term_id="contributor" >}} نیز هستند و
افزونه‌هایی را توسعه می‌دهند که به جامعه کوبرنتیز ارائه می‌شوند.
برخی دیگر افزونه‌های تجاری با کد بسته یا افزونه‌های اختصاصی هر سایت را توسعه می‌دهند.
