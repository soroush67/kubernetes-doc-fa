مجموعه‌ای از مسیرهای مرتبط در API کوبرنتیز.

<!--more-->

می‌توانید هر گروه API را با تغییر پیکربندی سرور API خود فعال یا غیرفعال کنید. همچنین می‌توانید مسیرهای مربوط به
{{< glossary_tooltip text="منابع" term_id="api-resource" >}} مشخصی را غیرفعال یا فعال کنید. گروه‌های API گسترش API کوبرنتیز را آسان‌تر می‌کنند.
گروه API در مسیر REST و نیز در فیلد `apiVersion` یک {{< glossary_tooltip text="آبجکت" term_id="object" >}} سریال‌سازی‌شده مشخص می‌شود.

* برای اطلاعات بیشتر، بخش [گروه API](/docs/concepts/overview/kubernetes-api/#api-groups-and-versioning) را مطالعه کنید.
