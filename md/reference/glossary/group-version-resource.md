روشی برای نمایش یکتای APIهای مشخص کوبرنتیز.

<!--more-->

Group Version Resourceها (GVRها) گروه API، نسخه API و _منبع_ (نام نوع آبجکت، آن‌گونه که در URI ظاهر می‌شود) را که برای دسترسی به یک شناسه (id) مشخص از آبجکت در کوبرنتیز به کار می‌روند، تعیین می‌کنند.
GVRها به شما امکان می‌دهند آبجکت‌های مختلف کوبرنتیز را تعریف و از یکدیگر متمایز کنید، و روشی برای دسترسی به
آبجکت‌ها مشخص کنید که حتی با تغییر APIها نیز پایدار باقی می‌ماند.

در این کاربرد، _منبع_ به یک منبع HTTP اشاره دارد. از آنجا که برخی APIها در سطح فضای نام (namespace) هستند، ممکن است یک GVR
به یک {{< glossary_tooltip text="منبع API" term_id="api-resource" >}} مشخص اشاره نکند.
