روشی برای نمایش یکتای APIهای مشخص در کوبرنتیز.

<!--more-->

هر Group Version Resource (به اختصار GVR) گروه API، نسخهٔ API و _منبع_ (نام نوع آبجکت، به همان شکلی که در URI ظاهر می‌شود) مرتبط با دسترسی به یک شناسهٔ مشخص از آبجکت در کوبرنتیز را تعیین می‌کند.
با GVRها می‌توانید آبجکت‌های مختلف کوبرنتیز را تعریف کنید و از یکدیگر متمایز سازید، و روشی برای دسترسی به آبجکت‌ها تعیین کنید که حتی با تغییر APIها پایدار بماند.

در این کاربرد، منظور از _منبع_ یک منبع HTTP است. از آنجا که برخی APIها وابسته به فضای نام (namespace) هستند، ممکن است یک GVR به یک {{< glossary_tooltip text="منبع API" term_id="api-resource" >}} مشخص اشاره نکند.
