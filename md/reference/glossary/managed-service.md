 یک محصول نرم‌افزاری که یک ارائه‌دهندهٔ شخص ثالث آن را نگهداری می‌کند.

<!--more--> 

از نمونه‌های سرویس‌های مدیریت‌شده (Managed Service) می‌توان به AWS EC2، Azure SQL Database و
GCP Pub/Sub اشاره کرد، اما سرویس مدیریت‌شده می‌تواند هر محصول نرم‌افزاری باشد که یک برنامه بتواند از آن استفاده کند.
