 یک محصول نرم‌افزاری که توسط یک ارائه‌دهنده شخص ثالث نگهداری می‌شود.

<!--more--> 

برخی از نمونه‌های سرویس‌های مدیریت‌شده عبارت‌اند از AWS EC2، Azure SQL Database و GCP Pub/Sub، اما این سرویس‌ها می‌توانند هر محصول نرم‌افزاری باشند که یک برنامه بتواند از آن استفاده کند.
