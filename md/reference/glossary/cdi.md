Container Device Interface (CDI) مشخصه‌ای است که نحوهٔ پیکربندی دستگاه‌ها را درون کانتینرها تعریف می‌کند. کوبرنتیز از CDI همراه با device pluginها و Dynamic Resource Allocation استفاده می‌کند تا بارهای کاری، تنظیمات دستگاه مانند bind mountها یا متغیرهای محیطی را از طریق runtime دریافت کنند.
