 {{< glossary_tooltip text="اعضای جامعه" term_id="member" >}} که به‌صورت جمعی بخشی یا جنبه‌ای مستمر از پروژه متن‌باز بزرگ‌تر کوبرنتیز را مدیریت می‌کنند.

<!--more--> 

اعضای یک SIG علاقه مشترکی به پیشبرد یک حوزه خاص دارند، مانند معماری، API machinery یا مستندات.
SIGها باید از [رهنمودهای حاکمیتی](https://github.com/kubernetes/community/blob/main/committee-steering/governance/sig-governance.md) SIG پیروی کنند، اما می‌توانند سیاست مشارکت و کانال‌های ارتباطی مخصوص به خود را داشته باشند.

برای اطلاعات بیشتر، مخزن [kubernetes/community](https://github.com/kubernetes/community) و فهرست فعلی [SIGها و گروه‌های کاری](https://github.com/kubernetes/community/blob/main/sig-list.md) را مشاهده کنید.
