 {{< glossary_tooltip text="اعضای جامعه" term_id="member" >}} که به‌طور جمعی بخش یا جنبه‌ای پیوسته از پروژهٔ متن‌باز بزرگ‌تر کوبرنتیز را مدیریت می‌کنند.

<!--more--> 

اعضای هر SIG علاقهٔ مشترکی به پیشبرد حوزه‌ای مشخص دارند؛ حوزه‌هایی مانند معماری، سازوکار API (API machinery) یا مستندات.
هر SIG باید از [رهنمودهای حاکمیتی](https://github.com/kubernetes/community/blob/main/committee-steering/governance/sig-governance.md) SIGها پیروی کند، اما می‌تواند سیاست مشارکت و کانال‌های ارتباطی خاص خود را داشته باشد.

برای اطلاعات بیشتر، مخزن [kubernetes/community](https://github.com/kubernetes/community) و فهرست کنونی [SIGها و گروه‌های کاری](https://github.com/kubernetes/community/blob/main/sig-list.md) را ببینید.
