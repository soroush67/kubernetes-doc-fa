ابزار `kOps` نه‌تنها به شما کمک می‌کند کلاسترهای کوبرنتیز در سطح محیط عملیاتی و با دسترس‌پذیری بالا را ایجاد، حذف، ارتقا و نگهداری کنید، بلکه زیرساخت ابری لازم را نیز فراهم می‌کند.

<!--more--> 

{{< note >}}
در حال حاضر AWS (Amazon Web Services) به‌طور رسمی پشتیبانی می‌شود. پشتیبانی از DigitalOcean، GCE و OpenStack در مرحلهٔ بتا و پشتیبانی از Azure در مرحلهٔ آلفا قرار دارد.
{{< /note >}}

ابزار `kOps` یک سامانهٔ خودکار برای فراهم‌سازی زیرساخت است:
  * نصب کاملاً خودکار
  * استفاده از DNS برای شناسایی کلاسترها
  * خودترمیمی: همه‌چیز در گروه‌های مقیاس‌پذیری خودکار (Auto-Scaling Groups) اجرا می‌شود
  * پشتیبانی از چندین سیستم‌عامل (Amazon Linux، Debian، Flatcar، RHEL، Rocky و Ubuntu)
  * پشتیبانی از دسترس‌پذیری بالا
  * امکان فراهم‌سازی مستقیم زیرساخت یا تولید مانیفست‌های terraform
