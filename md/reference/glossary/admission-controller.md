قطعه‌کدی که درخواست‌های ارسال‌شده به سرور API کوبرنتیز را پیش از ماندگار شدن آبجکت رهگیری می‌کند.

<!--more-->

کنترل‌کننده‌های پذیرش را می‌توان برای سرور API کوبرنتیز پیکربندی کرد. این کنترل‌کننده‌ها ممکن است از نوع «اعتبارسنج» (validating)، «تغییردهنده» (mutating) یا هر دو باشند. هر کنترل‌کنندهٔ پذیرشی می‌تواند درخواست را رد کند. کنترل‌کننده‌های تغییردهنده می‌توانند آبجکت‌هایی را که می‌پذیرند تغییر دهند، اما کنترل‌کننده‌های اعتبارسنج چنین امکانی ندارند.
