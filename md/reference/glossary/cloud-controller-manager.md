 مدیر کنترل‌کنندهٔ ابری یکی از مؤلفه‌های {{< glossary_tooltip text="control plane" term_id="control-plane" >}} کوبرنتیز است که منطق کنترلی ویژهٔ هر ابر را در خود جای داده است. با مدیر کنترل‌کنندهٔ ابری می‌توانید کلاستر خود را به API ارائه‌دهندهٔ ابری‌تان متصل کنید. این مؤلفه همچنین اجزایی را که با آن پلتفرم ابری تعامل دارند از اجزایی که فقط با کلاستر شما تعامل دارند جدا می‌کند.

<!--more-->

مؤلفهٔ cloud-controller-manager منطق تعامل میان کوبرنتیز و زیرساخت ابری زیربنایی را از هسته جدا می‌کند. به این ترتیب، ارائه‌دهندگان ابری می‌توانند قابلیت‌های خود را با سرعتی متفاوت از پروژهٔ اصلی کوبرنتیز منتشر کنند.
