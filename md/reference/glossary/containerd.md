 یک container runtime با تأکید بر سادگی، استحکام و قابلیت حمل

<!--more-->

containerd یک container runtime برای {{< glossary_tooltip text="کانتینر" term_id="container" >}} است که به‌صورت یک daemon روی لینوکس یا ویندوز اجرا می‌شود. containerd مسئولیت دریافت و ذخیره‌سازی ایمیج‌های کانتینر، اجرای کانتینرها، فراهم‌کردن دسترسی شبکه و موارد دیگر را بر عهده دارد.
