سازوکار کوبرنتیز برای در دسترس قرار دادن مقادیر فیلدهای Pod و کانتینر برای کدی که درون یک کانتینر اجرا می‌شود.
<!--more-->
گاهی مفید است که کانتینر بتواند اطلاعاتی دربارهٔ خودش داشته باشد، بی‌آنکه لازم باشد کد کانتینر را طوری تغییر دهید که مستقیماً به کوبرنتیز وابسته شود.

با downward API کوبرنتیز، کانتینرها می‌توانند اطلاعاتی دربارهٔ خودشان یا زمینهٔ اجرایشان در یک کلاستر کوبرنتیز دریافت کنند. برنامه‌های درون کانتینرها می‌توانند به این اطلاعات دسترسی داشته باشند، بدون اینکه لازم باشد خودِ برنامه به‌عنوان کلاینت API کوبرنتیز عمل کند.

برای در دسترس قرار دادن فیلدهای Pod و کانتینر برای یک کانتینر در حال اجرا، دو راه وجود دارد:

- استفاده از [متغیرهای محیطی](/docs/tasks/inject-data-application/environment-variable-expose-pod-information/)
- استفاده از [یک حجم (volume) از نوع `downwardAPI`](/docs/tasks/inject-data-application/downward-api-volume-expose-pod-information/)

این دو روش برای در دسترس قرار دادن فیلدهای Pod و کانتینر، روی هم رفته _downward API_ نامیده می‌شوند.
