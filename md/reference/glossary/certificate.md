 فایلی امن از نظر رمزنگاری که برای اعتبارسنجی دسترسی به کلاستر کوبرنتیز به کار می‌رود.

<!--more--> 

گواهی‌ها (Certificates) به برنامه‌های درون یک کلاستر کوبرنتیز امکان می‌دهند به‌صورت امن به API کوبرنتیز دسترسی داشته باشند. گواهی‌ها تأیید می‌کنند که کلاینت‌ها مجاز به دسترسی به API هستند.
