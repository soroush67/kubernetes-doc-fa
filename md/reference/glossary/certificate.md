 یک فایل امن از نظر رمزنگاری که برای اعتبارسنجی دسترسی به کلاستر کوبرنتیز استفاده می‌شود.

<!--more--> 

گواهی‌ها به برنامه‌های درون یک کلاستر کوبرنتیز امکان می‌دهند که به‌صورت امن به API کوبرنتیز دسترسی پیدا کنند. گواهی‌ها تأیید می‌کنند که کلاینت‌ها مجاز به دسترسی به API هستند.
