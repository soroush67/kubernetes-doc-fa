این صفحه جزئیات سازگاری نسخه‌های [API افزونهٔ دستگاه](https://github.com/kubernetes/kubelet/tree/master/pkg/apis/deviceplugin) (device plugin API) کوبرنتیز را با نسخه‌های مختلف خود کوبرنتیز ارائه می‌کند.

## ماتریس سازگاری

|                 |  `v1alpha1` | `v1beta1`   |
|-----------------|-------------|-------------|
| کوبرنتیز 1.21 |  -          | ✓           |
| کوبرنتیز 1.22 |  -          | ✓           |
| کوبرنتیز 1.23 |  -          | ✓           |
| کوبرنتیز 1.24 |  -          | ✓           |
| کوبرنتیز 1.25 |  -          | ✓           |
| کوبرنتیز 1.26 |  -          | ✓           |

راهنما:

* `✓` قابلیت‌ها و آبجکت‌های API در API افزونهٔ دستگاه و نسخهٔ کوبرنتیز دقیقاً یکسان هستند.
* `+` API افزونهٔ دستگاه قابلیت‌ها یا آبجکت‌هایی از API دارد که ممکن است در کلاستر کوبرنتیز وجود نداشته باشند؛ زیرا یا فراخوانی‌های جدیدی به API افزونهٔ دستگاه اضافه شده یا سرور یک فراخوانی قدیمی API را حذف کرده است. با این حال، همهٔ بخش‌های مشترک آن‌ها (بیشتر APIهای دیگر) کار خواهند کرد. توجه کنید که APIهای آلفا ممکن است از یک انتشار فرعی به انتشار فرعی بعدی ناپدید شوند یا تغییرات چشمگیری داشته باشند.
* `-` کلاستر کوبرنتیز قابلیت‌هایی دارد که API افزونهٔ دستگاه نمی‌تواند از آن‌ها استفاده کند؛ زیرا یا سرور فراخوانی‌های جدیدی به API اضافه کرده یا یک فراخوانی قدیمی از API افزونهٔ دستگاه حذف شده است. با این حال، همهٔ بخش‌های مشترک آن‌ها (بیشتر APIها) کار خواهند کرد.
