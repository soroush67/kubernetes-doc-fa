برای گزارش یک مشکل امنیتی، لطفاً از [فرایند افشای امنیتی کوبرنتیز](/docs/reference/issues-security/security/#report-a-vulnerability) پیروی کنید.

کار روی کد کوبرنتیز و مشکلات عمومی آن با استفاده از [GitHub Issues](https://github.com/kubernetes/kubernetes/issues/) پیگیری می‌شود.

* [فهرست رسمی CVEهای شناخته‌شده](/docs/reference/issues-security/official-cve-feed/)
  (آسیب‌پذیری‌های امنیتی) که [کمیته پاسخ امنیتی](https://github.com/kubernetes/committee-security-response)
  (Security Response Committee) اعلام کرده است
* [مشکلات مرتبط با CVE در GitHub](https://github.com/kubernetes/kubernetes/issues?utf8=%E2%9C%93&q=is%3Aissue+label%3Aarea%2Fsecurity+in%3Atitle+CVE)

اطلاعیه‌های مرتبط با امنیت به فهرست پستی [kubernetes-security-announce@googlegroups.com](https://groups.google.com/forum/#!forum/kubernetes-security-announce) ارسال می‌شوند.
