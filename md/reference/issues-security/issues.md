برای گزارش یک مشکل امنیتی، لطفاً [فرایند افشای امنیتی کوبرنتیز](/docs/reference/issues-security/security/#report-a-vulnerability) را دنبال کنید.

کار روی کد کوبرنتیز و مسائل عمومی با استفاده از [GitHub Issues](https://github.com/kubernetes/kubernetes/issues/) پیگیری می‌شود.

* [فهرست رسمی CVEهای شناخته‌شده](/docs/reference/issues-security/official-cve-feed/)
  (آسیب‌پذیری‌های امنیتی) که توسط
  [کمیته پاسخ‌گویی امنیتی (Security Response Committee)](https://github.com/kubernetes/committee-security-response)
  اعلام شده‌اند
* [مسائل GitHub مرتبط با CVE](https://github.com/kubernetes/kubernetes/issues?utf8=%E2%9C%93&q=is%3Aissue+label%3Aarea%2Fsecurity+in%3Atitle+CVE)

اطلاعیه‌های مرتبط با امنیت به فهرست پستی [kubernetes-security-announce@googlegroups.com](https://groups.google.com/forum/#!forum/kubernetes-security-announce) ارسال می‌شوند.
