## IngressClass {#IngressClass}

IngressClass کلاس یک Ingress را نشان می‌دهد که Ingress Spec به آن ارجاع می‌دهد. می‌توان از حاشیه‌نویسی (annotation) با نام `ingressclass.kubernetes.io/is-default-class` برای مشخص کردن این نکته استفاده کرد که یک IngressClass باید به‌عنوان پیش‌فرض در نظر گرفته شود. هنگامی که این حاشیه‌نویسی روی یک منبع IngressClass برابر true تنظیم شده باشد، این کلاس پیش‌فرض به منابع Ingress جدیدی که کلاس برای آن‌ها مشخص نشده است اختصاص داده می‌شود.
