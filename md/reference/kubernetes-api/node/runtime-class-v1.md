## RuntimeClass {#RuntimeClass}

RuntimeClass یک کلاس از محیط اجرای کانتینر را که در کلاستر پشتیبانی می‌شود تعریف می‌کند. از RuntimeClass برای تعیین محیط اجرای کانتینری استفاده می‌شود که تمام کانتینرهای یک Pod با آن اجرا می‌شوند. RuntimeClassها را کاربر یا فراهم‌کننده کلاستر به‌صورت دستی تعریف می‌کند و در PodSpec به آن‌ها ارجاع داده می‌شود. Kubelet مسئول تعیین مقدار مرجع RuntimeClassName پیش از اجرای Pod است. برای جزئیات بیشتر، به https://kubernetes.io/docs/concepts/containers/runtime-class/ مراجعه کنید.
