زبان **KYAML** زیرمجموعه‌ای امن‌تر و کم‌ابهام‌تر از YAML است. این زبان به‌طور خاص برای کوبرنتیز طراحی شده است و مشکلات رایج YAML، مانند حساسیت به فاصله‌های خالی (whitespace) و تبدیل ضمنی نوع داده‌ها (implicit type coercion)، را برطرف می‌کند و در عین حال سازگاری کامل خود را با تجزیه‌گرها (parser) و ابزارهای موجود YAML حفظ می‌کند.

<!-- body -->
این مرجع، نحو (syntax) زبان KYAML را شرح می‌دهد.

## شروع کار با KYAML

وابستگی YAML به تورفتگی و تبدیل ضمنی نوع داده‌ها اغلب به خطاهای پیکربندی منجر می‌شود، به‌ویژه در خطوط لوله CI/CD و سامانه‌های قالب‌سازی مانند Helm. زبان KYAML با الزام به نحو و ساختار صریح، این مشکلات را از میان برمی‌دارد و پیکربندی‌ها را قابل‌اعتمادتر می‌کند و اشکال‌زدایی آن‌ها را آسان‌تر می‌سازد.

### ساختار پایه

زبان KYAML از نحو *سبک جریانی* (flow style) استفاده می‌کند که در آن `{}` برای آبجکت‌ها و `[]` برای آرایه‌ها به کار می‌رود. همه مقادیر رشته‌ای باید **درون علامت نقل‌قول دوتایی** قرار گیرند.

```yaml
---
{
  apiVersion: "v1",
  kind: "Pod",
  metadata: {
    name: "my-pod",
    labels: {
      app: "demo"
    },
  },
  spec: {
    containers: [{
      name: "nginx",
      image: "nginx:1.20"
    }]
  }
}
```
