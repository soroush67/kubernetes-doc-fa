**KYAML** زیرمجموعه‌ای امن‌تر و کم‌ابهام‌تر از YAML است. KYAML که به‌طور ویژه برای کوبرنتیز طراحی شده است، مشکلات رایج YAML مانند حساسیت به فاصله‌گذاری (whitespace) و تبدیل ضمنی نوع (implicit type coercion) را برطرف می‌کند و در عین حال سازگاری کامل با تجزیه‌گرها (parser) و ابزارهای موجود YAML را حفظ می‌کند.

<!-- body -->
این مرجع، نحو (syntax) KYAML را شرح می‌دهد.

## شروع کار با KYAML

اتکای YAML به تورفتگی و تبدیل ضمنی نوع اغلب به خطاهای پیکربندی منجر می‌شود، به‌ویژه در پایپ‌لاین‌های CI/CD و سامانه‌های قالب‌سازی مانند Helm. KYAML با الزام نحو و ساختار صریح، این مشکلات را از میان برمی‌دارد و پیکربندی‌ها را قابل‌اعتمادتر و اشکال‌زدایی آن‌ها را آسان‌تر می‌کند.

### ساختار پایه

KYAML از نحو *flow style* با `{}` برای آبجکت‌ها و `[]` برای آرایه‌ها استفاده می‌کند. همه مقادیر رشته‌ای باید **درون دابل‌کوتیشن** قرار بگیرند.

```yaml
---
{
  apiVersion: "v1",
  kind: "Pod",
  metadata: {
    name: "my-pod",
    labels: {
      app: "demo"
    },
  },
  spec: {
    containers: [{
      name: "nginx",
      image: "nginx:1.20"
    }]
  }
}
```
