ابزار kubectl یک ابزار خط فرمان است که با استفاده از API کوبرنتیز با کلاسترهای کوبرنتیز تعامل می‌کند. با این ابزار می‌توانید برنامه‌ها را مستقر کنید، منابع را بررسی کنید و بارهای کاری را مدیریت کنید.

تمرکز این کتاب بر استفاده از kubectl برای مدیریت اعلانی (declarative) برنامه‌ها در کوبرنتیز است، اما سایر قابلیت‌های kubectl را نیز پوشش می‌دهد.

## خانواده‌های دستورات

بیشتر دستورات kubectl معمولاً در یکی از چند دسته‌ی زیر قرار می‌گیرند:

| نوع                                   | کاربرد                   | توضیحات                                        |
|----------------------------------------|----------------------------|----------------------------------------------------|
| مدیریت اعلانی منابع        | استقرار و عملیات (مانند GitOps)   | مدیریت اعلانی بارهای کاری کوبرنتیز با استفاده از پیکربندی منابع     |
| مدیریت دستوری (imperative) منابع         | فقط برای توسعه           | اجرای دستورات برای مدیریت بارهای کاری کوبرنتیز با استفاده از آرگومان‌ها و فلگ‌های خط فرمان |
| نمایش وضعیت بار کاری | اشکال‌زدایی  | نمایش اطلاعات مربوط به بارهای کاری |
| تعامل با کانتینرها | اشکال‌زدایی  | اجرای دستور (exec)، اتصال (attach)، کپی (cp) و لاگ‌ها (logs) |
| مدیریت کلاستر | عملیات کلاستر | تخلیه (drain) و قرنطینه (cordon) کردن نودها |

## مدیریت اعلانی برنامه‌ها

روش ترجیحی برای مدیریت منابع، استفاده از فایل‌های اعلانی به نام پیکربندی منابع همراه با دستور *Apply* در kubectl است. این دستور ساختار فایل‌های محلی (یا راه دور) را می‌خواند و وضعیت کلاستر را طوری تغییر می‌دهد که با هدف اعلام‌شده مطابقت داشته باشد.

{{< alert color="success" title="Apply" >}}
دستور Apply سازوکار ترجیحی برای مدیریت منابع در یک کلاستر کوبرنتیز است.
{{< /alert >}}

## نمایش وضعیت بارهای کاری

کاربران باید بتوانند وضعیت بارهای کاری را مشاهده کنند.

- نمایش خلاصه‌ی وضعیت و اطلاعات منابع
- نمایش کامل وضعیت و اطلاعات منابع
- نمایش فیلدهای مشخصی از منابع
- جست‌وجوی منابعی که با برچسب‌ها مطابقت دارند

## اشکال‌زدایی بارهای کاری

ابزار kubectl با ارائه‌ی دستوراتی برای کارهای زیر از اشکال‌زدایی پشتیبانی می‌کند:

- نمایش لاگ‌های کانتینر
- نمایش رویدادهای کلاستر
- اجرای دستور در کانتینر یا اتصال به آن
- کپی فایل‌ها از کانتینرهای داخل کلاستر به سیستم فایل کاربر

## مدیریت کلاستر

گاهی کاربران باید عملیاتی را روی نودهای کلاستر انجام دهند. ابزار kubectl دستوراتی برای تخلیه‌ی بارهای کاری از یک نود فراهم می‌کند تا بتوان آن نود را از سرویس خارج کرد یا اشکال‌زدایی کرد.

## دستورات سطح‌بالا (Porcelain)

ممکن است کاربران استفاده از پیکربندی منابع را برای *توسعه* بیش از حد مفصل بدانند و ترجیح دهند با یک گردش کار شبیه به پوسته (shell)، به‌صورت *دستوری* با کلاستر کار کنند. ابزار kubectl دستورات سطح‌بالایی برای تولید و تغییر منابع ارائه می‌دهد.

- تولید و ایجاد منابعی مانند Deploymentها، StatefulSetها، Serviceها، ConfigMapها و غیره
- تنظیم فیلدهای منابع
- ویرایش منابع (به‌صورت زنده) در یک ویرایشگر متن

{{< alert color="warning" title="Porcelain for Dev Only" >}}
دستورات سطح‌بالا برای آزمایش بارهای کاری در یک کلاستر توسعه در زمان صرفه‌جویی می‌کنند، اما نباید در محیط عملیاتی (production) از آن‌ها استفاده کرد.
{{< /alert >}}
