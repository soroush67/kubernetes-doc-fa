## {{% heading "synopsis" %}}


این دستور قواعد آبجکت‌های RBAC از نوع role، role binding، cluster role و cluster role binding را تطبیق می‌دهد (reconcile).

 آبجکت‌هایی که وجود ندارند ایجاد می‌شوند و برای آبجکت‌های وابسته به فضای نام (namespace)، در صورت نیاز فضای نام دربرگیرندهٔ آن‌ها نیز ایجاد می‌شود.

 نقش‌های موجود به‌روزرسانی می‌شوند تا مجوزهای موجود در آبجکت‌های ورودی را دربر بگیرند و اگر ‎--remove-extra-permissions مشخص شده باشد، مجوزهای اضافی از آن‌ها حذف می‌شود.

 اتصال‌های (binding) موجود به‌روزرسانی می‌شوند تا سوژه‌های (subject) موجود در آبجکت‌های ورودی را دربر بگیرند و اگر ‎--remove-extra-subjects مشخص شده باشد، سوژه‌های اضافی از آن‌ها حذف می‌شود.

 برای منابع RBAC، استفاده از این دستور بر 'apply' ترجیح دارد، زیرا ادغام قواعد و سوژه‌ها با درنظرگرفتن معنای آن‌ها انجام می‌شود.

```
kubectl auth reconcile -f FILENAME
```

## {{% heading "examples" %}}

```
  # Reconcile RBAC resources from a file
  kubectl auth reconcile -f my-rbac-rules.yaml
```
