## {{% heading "synopsis" %}}


این دستور انتخابگر (selector) را روی یک منبع تنظیم می‌کند. توجه کنید که اگر منبع پیش از اجرای 'set selector' انتخابگری داشته باشد، انتخابگر جدید جایگزین انتخابگر قبلی می‌شود.

 هر انتخابگر باید با یک حرف یا عدد آغاز شود و می‌تواند حداکثر ۶۳ نویسه شامل حروف، اعداد، خط تیره، نقطه و زیرخط داشته باشد. اگر ‎--resource-version مشخص شده باشد، به‌روزرسانی‌ها از همین نسخهٔ منبع استفاده می‌کنند؛ در غیر این صورت، نسخهٔ فعلی منبع (resource-version) به کار می‌رود. توجه: در حال حاضر انتخابگرها را فقط می‌توان روی آبجکت‌های Service تنظیم کرد.

```
kubectl set selector (-f FILENAME | TYPE NAME) EXPRESSIONS [--resource-version=version]
```

## {{% heading "examples" %}}

```
  # Set the labels and selector before creating a deployment/service pair
  kubectl create service clusterip my-svc --clusterip="None" -o yaml --dry-run=client | kubectl set selector --local -f - 'environment=qa' -o yaml | kubectl create -f -
  kubectl create deployment my-dep --image=nginx -o yaml --dry-run=client | kubectl label --local -f - environment=qa -o yaml | kubectl create -f -
```
