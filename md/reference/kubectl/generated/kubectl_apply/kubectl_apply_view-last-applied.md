## {{% heading "synopsis" %}}


با این دستور می‌توانید آخرین حاشیه‌نویسی‌های (annotations) last-applied-configuration را بر اساس نوع/نام یا از روی فایل مشاهده کنید.

 خروجی به‌طور پیش‌فرض با قالب YAML در خروجی استاندارد (stdout) چاپ می‌شود. برای تغییر قالب خروجی می‌توانید از گزینهٔ ‎-o استفاده کنید.

```
kubectl apply view-last-applied (TYPE [NAME | -l label] | TYPE/NAME | -f FILENAME)
```

## {{% heading "examples" %}}

```
  # View the last-applied-configuration annotations by type/name in YAML
  kubectl apply view-last-applied deployment/nginx
  
  # View the last-applied-configuration annotations by file in JSON
  kubectl apply view-last-applied -f deploy.yaml -o json
```
