## {{% heading "synopsis" %}}


آخرین حاشیه‌نویسی‌های (annotations) last-applied-configuration منابع را با ویرایشگر پیش‌فرض ویرایش کنید.

 با دستور edit-last-applied می‌توانید هر منبع API را که از طریق ابزارهای خط فرمان قابل بازیابی است، مستقیماً ویرایش کنید. این دستور ویرایشگری را باز می‌کند که در متغیرهای محیطی KUBE_EDITOR یا EDITOR تعریف شده است؛ در غیر این صورت، در لینوکس از 'vi' و در ویندوز از 'notepad' استفاده می‌کند. می‌توانید چند آبجکت را ویرایش کنید، اما تغییرات یکی‌یکی اعمال می‌شوند. این دستور هم نام فایل و هم آرگومان‌های خط فرمان را می‌پذیرد، اما فایل‌هایی که به آن‌ها اشاره می‌کنید باید نسخه‌هایی از منابع باشند که پیش‌تر ذخیره شده‌اند.

 قالب پیش‌فرض YAML است. برای ویرایش در قالب JSON، گزینهٔ "-o json" را مشخص کنید.

 با فلگ --windows-line-endings می‌توانید استفاده از پایان خط ویندوز را اجباری کنید؛ در غیر این صورت، پایان خط پیش‌فرض سیستم‌عامل شما به کار می‌رود.

 اگر هنگام به‌روزرسانی خطایی رخ دهد، یک فایل موقت حاوی تغییرات اعمال‌نشدهٔ شما روی دیسک ایجاد می‌شود. رایج‌ترین خطا هنگام به‌روزرسانی یک منبع این است که ویرایشگر دیگری همان منبع را روی سرور تغییر داده باشد. در این صورت، باید تغییرات خود را روی نسخهٔ جدیدتر منبع اعمال کنید، یا نسخهٔ موقتِ ذخیره‌شدهٔ خود را به‌روزرسانی کنید تا آخرین نسخهٔ منبع را در بر بگیرد.

```
kubectl apply edit-last-applied (RESOURCE/NAME | -f FILENAME)
```

## {{% heading "examples" %}}

```
  # Edit the last-applied-configuration annotations by type/name in YAML
  kubectl apply edit-last-applied deployment/nginx
  
  # Edit the last-applied-configuration annotations by file in JSON
  kubectl apply edit-last-applied -f deploy.yaml -o json
```
