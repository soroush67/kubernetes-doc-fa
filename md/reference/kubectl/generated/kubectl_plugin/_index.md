## {{% heading "synopsis" %}}


این دستور ابزارهایی برای تعامل با افزونه‌ها (plugins) فراهم می‌کند.

 افزونه‌ها قابلیت‌های تکمیلی‌ای فراهم می‌کنند که بخشی از توزیع اصلی خط فرمان نیستند. برای کسب اطلاعات بیشتر درباره‌ی نحوه‌ی نوشتن افزونه‌های خودتان، لطفاً به مستندات و نمونه‌ها مراجعه کنید.

 ساده‌ترین راه برای یافتن و نصب افزونه‌ها، استفاده از krew است که یکی از زیرپروژه‌های کوبرنتیز است: [krew.sigs.k8s.io]. برای نصب krew به نشانی https://krew.sigs.k8s.io/docs/user-guide/setup/install مراجعه کنید.

```
kubectl plugin [flags]
```

## {{% heading "examples" %}}

```
  # List all available plugins
  kubectl plugin list
  
  # List only binary names of available plugins without paths
  kubectl plugin list --name-only
```
