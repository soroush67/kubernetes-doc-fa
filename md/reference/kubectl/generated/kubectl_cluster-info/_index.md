## {{% heading "synopsis" %}}


این دستور نشانی‌های control plane و سرویس‌هایی را که برچسب kubernetes.io/cluster-service=true دارند نمایش می‌دهد. برای اشکال‌زدایی و عیب‌یابی بیشتر مشکلات کلاستر، از دستور 'kubectl cluster-info dump' استفاده کنید.

```
kubectl cluster-info [flags]
```

## {{% heading "examples" %}}

```
  # Print the address of the control plane and cluster services
  kubectl cluster-info
```
