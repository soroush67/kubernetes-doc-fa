## {{% heading "synopsis" %}}


یک منبع را با ویرایشگر پیش‌فرض ویرایش کنید.

 با فرمان edit می‌توانید هر منبع API را که از طریق ابزارهای خط فرمان قابل دریافت است، مستقیماً ویرایش کنید. این فرمان ویرایشگری را باز می‌کند که در متغیرهای محیطی KUBE_EDITOR یا EDITOR تعریف شده است؛ اگر هیچ‌کدام تعریف نشده باشد، در لینوکس از 'vi' و در ویندوز از 'notepad' استفاده می‌کند. هنگام باز کردن ویرایشگر، ابتدا تلاش می‌شود از پوسته‌ای (shell) استفاده شود که در متغیر محیطی 'SHELL' تعریف شده است. اگر این متغیر تعریف نشده باشد، پوستهٔ پیش‌فرض به کار می‌رود که در لینوکس '/bin/bash' و در ویندوز 'cmd' است.

 می‌توانید چند آبجکت را ویرایش کنید، اما تغییرات یکی‌یکی اعمال می‌شوند. این فرمان علاوه بر آرگومان‌های خط فرمان، نام فایل را نیز می‌پذیرد، اما فایل‌هایی که به آن‌ها اشاره می‌کنید باید نسخه‌هایی از منابع باشند که پیش‌تر ذخیره شده‌اند.

 ویرایش با همان نسخهٔ API انجام می‌شود که برای دریافت منبع به کار رفته است. برای ویرایش با یک نسخهٔ مشخص از API، نام کامل منبع را همراه با نسخه و گروه آن بنویسید.

 قالب پیش‌فرض YAML است. برای ویرایش در قالب JSON، گزینهٔ "-o json" را مشخص کنید.

 با فلگ --windows-line-endings می‌توانید استفاده از پایان خط ویندوز را اجباری کنید؛ در غیر این صورت، پایان خط پیش‌فرض سیستم‌عامل شما به کار می‌رود.

 اگر هنگام به‌روزرسانی خطایی رخ دهد، یک فایل موقت روی دیسک ایجاد می‌شود که تغییرات اعمال‌نشدهٔ شما را در خود دارد. رایج‌ترین خطا هنگام به‌روزرسانی یک منبع این است که ویرایشگر دیگری همان منبع را روی سرور تغییر داده باشد. در این صورت، باید تغییرات خود را روی نسخهٔ جدیدتر منبع اعمال کنید یا نسخهٔ موقت ذخیره‌شدهٔ خود را به‌روز کنید تا آخرین نسخهٔ منبع را در بر بگیرد.

```
kubectl edit (RESOURCE/NAME | -f FILENAME)
```

## {{% heading "examples" %}}

```
  # Edit the service named 'registry'
  kubectl edit svc/registry
  
  # Use an alternative editor
  KUBE_EDITOR="nano" kubectl edit svc/registry
  
  # Edit the job 'myjob' in JSON using the v1 API format
  kubectl edit job.v1.batch/myjob -o json
  
  # Edit the deployment 'mydeployment' in YAML and save the modified config in its annotation
  kubectl edit deployment/mydeployment -o yaml --save-config
  
  # Edit the 'status' subresource for the 'mydeployment' deployment
  kubectl edit deployment mydeployment --subresource='status'
```
