## {{% heading "synopsis" %}}


میزان مصرف منابع (CPU/حافظه) پادها را نمایش می‌دهد.

 با فرمان «top pod» می‌توانید میزان مصرف منابع پادها را مشاهده کنید.

 به دلیل تأخیر در خط لوله‌ی متریک‌ها (metrics pipeline)، ممکن است این اطلاعات تا چند دقیقه پس از ایجاد پاد در دسترس نباشند.

```
kubectl top pod [NAME | -l label]
```

## {{% heading "examples" %}}

```
  # Show metrics for all pods in the default namespace
  kubectl top pod
  
  # Show metrics for all pods in the given namespace
  kubectl top pod --namespace=NAMESPACE
  
  # Show metrics for a given pod and its containers
  kubectl top pod POD_NAME --containers
  
  # Show metrics for the pods defined by label name=myLabel
  kubectl top pod -l name=myLabel
```
