## {{% heading "synopsis" %}}


این دستور میزان استفاده از منابع (CPU/حافظه) نودها را نمایش می‌دهد.

 با فرمان top-node می‌توانید میزان مصرف منابع نودها را مشاهده کنید.

```
kubectl top node [NAME | -l label]
```

## {{% heading "examples" %}}

```
  # Show metrics for all nodes
  kubectl top node
  
  # Show metrics for a given node
  kubectl top node NODE_NAME
```
