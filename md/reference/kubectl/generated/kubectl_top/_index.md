## {{% heading "synopsis" %}}


میزان مصرف منابع (CPU/حافظه) را نمایش می‌دهد.

 این فرمان نمایی از مصرف اخیر منابع در نودها و پادها ارائه می‌دهد. داده‌های سنجه (metrics) را از Metrics Server دریافت می‌کند و Metrics Server نیز این داده‌ها را از kubelet هر نود گردآوری می‌کند. برای کارکرد این فرمان، Metrics Server باید در کلاستر نصب و در حال اجرا باشد.

 سنجه‌های نمایش‌داده‌شده به‌طور خاص برای تصمیم‌های مقیاس‌دهی خودکار کوبرنتیز بهینه شده‌اند؛ مانند تصمیم‌هایی که Horizontal Pod Autoscaler (HPA) و Vertical Pod Autoscaler (VPA) می‌گیرند. به همین دلیل، ممکن است این مقادیر با مقادیر ابزارهای استاندارد سیستم‌عامل مانند 'top' یکسان نباشند، زیرا هدف از طراحی این سنجه‌ها فراهم کردن سیگنالی پایدار برای مقیاس‌دهنده‌های خودکار است، نه دقت کامل.

 پرسش‌های متداول درباره‌ی Metrics Server: https://github.com/kubernetes-sigs/metrics-server/blob/master/FAQ.md

 چه زمانی از این فرمان استفاده کنیم:

  *  برای بررسی‌های سریع و لحظه‌ای مصرف منابع (برای مثال، تشخیص اینکه کدام پادها در یک نگاه بیشترین منابع را مصرف می‌کنند، یا به دست آوردن برداشتی سریع از بار نودها)
  *  برای درک الگوهای کنونی مصرف منابع
  *  برای اعتبارسنجی رفتار پیکربندی‌های HPA یا VPA، با مشاهده‌ی سنجه‌هایی که این ابزارها برای تصمیم‌های مقیاس‌دهی به کار می‌برند.

 این فرمان جایگزینی برای راهکارهای پایش کامل نیست. هدف اصلی طراحی آن فراهم کردن سیگنالی کم‌هزینه برای مقیاس‌دهنده‌های خودکار است، نه اینکه ابزار پایشی کاملاً دقیقی باشد. برای گزارش‌دهی با دقت بالا، تحلیل داده‌های تاریخی، داشبوردسازی یا هشداردهی، باید از یک راهکار پایش اختصاصی استفاده کنید.

```
kubectl top [flags]
```
