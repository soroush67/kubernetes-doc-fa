## {{% heading "synopsis" %}}


این دستور تنظیمات ادغام‌شدهٔ kubeconfig یا محتوای یک فایل kubeconfig مشخص را نمایش می‌دهد.

برای استخراج مقادیر مشخص با یک عبارت jsonpath می‌توانید از `--output jsonpath={...}` استفاده کنید.

```
kubectl config view [flags]
```

## {{% heading "examples" %}}

```
  # Show merged kubeconfig settings
  kubectl config view
  
  # Show merged kubeconfig settings, raw certificate data, and exposed secrets
  kubectl config view --raw
  
  # Get the password for the e2e user
  kubectl config view -o jsonpath='{.users[?(@.name == "e2e")].user.password}'
```
