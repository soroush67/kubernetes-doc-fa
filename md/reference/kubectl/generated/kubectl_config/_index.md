## {{% heading "synopsis" %}}


با استفاده از زیرفرمان‌هایی مانند «kubectl config set current-context my-context» فایل‌های kubeconfig را ویرایش کنید.

 ترتیب بارگذاری از این قواعد پیروی می‌کند:

  1.  اگر فلگ ‎--kubeconfig تنظیم شده باشد، فقط همان فایل بارگذاری می‌شود. این فلگ را فقط یک بار می‌توان تنظیم کرد و هیچ ادغامی انجام نمی‌شود.
  2.  اگر متغیر محیطی ‎$KUBECONFIG تنظیم شده باشد، به‌عنوان فهرستی از مسیرها (مطابق قواعد معمول جداسازی مسیر در سیستم شما) به کار می‌رود و این مسیرها با هم ادغام می‌شوند. هنگام تغییر یک مقدار، آن مقدار در همان فایلی تغییر می‌کند که بخش مربوط در آن تعریف شده است. هنگام ایجاد یک مقدار، آن مقدار در نخستین فایل موجود ایجاد می‌شود. اگر هیچ‌یک از فایل‌های این زنجیره وجود نداشته باشد، آخرین فایل فهرست ایجاد می‌شود.
  3.  در غیر این صورت، از ‎${HOME}/.kube/config استفاده می‌شود و هیچ ادغامی انجام نمی‌شود.

```
kubectl config SUBCOMMAND
```
