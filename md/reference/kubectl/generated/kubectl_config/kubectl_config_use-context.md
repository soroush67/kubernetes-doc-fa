## {{% heading "synopsis" %}}


این دستور مقدار current-context را در یک فایل kubeconfig تنظیم می‌کند.

```
kubectl config use-context CONTEXT_NAME
```

## {{% heading "examples" %}}

```
  # Use the context for the minikube cluster
  kubectl config use-context minikube
```
