## {{% heading "synopsis" %}}


این دستور کانتکست (context) مشخص‌شده را از فایل kubeconfig حذف می‌کند.

```
kubectl config delete-context NAME
```

## {{% heading "examples" %}}

```
  # Delete the context for the minikube cluster
  kubectl config delete-context minikube
```
