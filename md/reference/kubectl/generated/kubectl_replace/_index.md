## {{% heading "synopsis" %}}


این دستور یک منبع را با استفاده از نام فایل یا ورودی استاندارد جایگزین می‌کند.

 هر دو قالب JSON و YAML پذیرفته می‌شوند. هنگام جایگزین کردن یک منبع موجود، باید مشخصات (spec) کامل منبع ارائه شود. این مشخصات را می‌توان با دستور زیر به دست آورد:

        $ kubectl get TYPE NAME -o yaml

```
kubectl replace -f FILENAME
```

## {{% heading "examples" %}}

```
  # Replace a pod using the data in pod.json
  kubectl replace -f ./pod.json
  
  # Replace a pod based on the JSON passed into stdin
  cat pod.json | kubectl replace -f -
  
  # Update a single-container pod's image version (tag) to v4
  kubectl get pod mypod -o yaml | sed 's/\(image: myimage\):.*$/\1:v4/' | kubectl replace -f -
  
  # Force replace, delete and then re-create the resource
  kubectl replace --force -f ./pod.json
```
