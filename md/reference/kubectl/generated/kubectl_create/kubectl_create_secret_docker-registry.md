## {{% heading "synopsis" %}}


یک Secret جدید برای استفاده با رجیستری‌های Docker ایجاد می‌کند.
        
        از Secretهای نوع dockercfg برای احراز هویت در رجیستری‌های Docker استفاده می‌شود.
        
        هنگام استفاده از خط فرمان Docker برای push کردن ایمیج‌ها، می‌توانید با اجرای این دستور در یک رجیستری مشخص احراز هویت کنید: '$ docker login DOCKER_REGISTRY_SERVER --username=DOCKER_USER --password=DOCKER_PASSWORD --email=DOCKER_EMAIL'.
        
 این دستور یک فایل ~/.dockercfg ایجاد می‌کند که فرمان‌های بعدی 'docker push' و 'docker pull' از آن برای احراز هویت در رجیستری استفاده می‌کنند. وارد کردن نشانی ایمیل اختیاری است.

        هنگام ایجاد برنامه‌ها، ممکن است از رجیستری Docker‌ای استفاده کنید که به احراز هویت نیاز دارد. برای اینکه نودها بتوانند به نمایندگی از شما ایمیج‌ها را pull کنند، باید اطلاعات احراز هویت (credentials) را در اختیار داشته باشند. می‌توانید این اطلاعات را با ایجاد یک Secret از نوع dockercfg و پیوست کردن آن به حساب سرویس (service account) خود فراهم کنید.

```
kubectl create secret docker-registry NAME --docker-username=user --docker-password=password --docker-email=email [--docker-server=string] [--from-file=[key=]source] [--dry-run=server|client|none]
```

## {{% heading "examples" %}}

```
  # If you do not already have a .dockercfg file, create a dockercfg secret directly
  kubectl create secret docker-registry my-secret --docker-server=DOCKER_REGISTRY_SERVER --docker-username=DOCKER_USER --docker-password=DOCKER_PASSWORD --docker-email=DOCKER_EMAIL
  
  # Create a new secret named my-secret from ~/.docker/config.json
  kubectl create secret docker-registry my-secret --from-file=path/to/.docker/config.json
```
