## {{% heading "synopsis" %}}


این دستور یک config map را بر اساس یک فایل، یک دایرکتوری یا یک مقدار صریح (literal) مشخص‌شده ایجاد می‌کند.

 هر config map می‌تواند یک یا چند جفت کلید/مقدار را در خود بسته‌بندی کند.

 هنگام ایجاد config map بر اساس یک فایل، کلید به‌طور پیش‌فرض نام پایه (basename) فایل و مقدار به‌طور پیش‌فرض محتوای فایل خواهد بود. اگر نام پایه کلید معتبری نباشد، می‌توانید کلید دیگری مشخص کنید.

 هنگام ایجاد config map بر اساس یک دایرکتوری، هر فایلی از آن دایرکتوری که نام پایه‌اش کلید معتبری باشد، در config map بسته‌بندی می‌شود. همهٔ ورودی‌های دایرکتوری به‌جز فایل‌های معمولی نادیده گرفته می‌شوند (برای مثال زیردایرکتوری‌ها، پیوندهای نمادین، دستگاه‌ها، pipeها و غیره).

```
kubectl create configmap NAME [--from-file=[key=]source] [--from-literal=key1=value1] [--dry-run=server|client|none]
```

## {{% heading "examples" %}}

```
  # Create a new config map named my-config based on folder bar
  kubectl create configmap my-config --from-file=path/to/bar
  
  # Create a new config map named my-config with specified keys instead of file basenames on disk
  kubectl create configmap my-config --from-file=key1=/path/to/bar/file1.txt --from-file=key2=/path/to/bar/file2.txt
  
  # Create a new config map named my-config with key1=config1 and key2=config2
  kubectl create configmap my-config --from-literal=key1=config1 --from-literal=key2=config2
  
  # Create a new config map named my-config with key=value pairs from an env file
  kubectl create configmap my-config --from-env-file=path/to/bar.env
```
