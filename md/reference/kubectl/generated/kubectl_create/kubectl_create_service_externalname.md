## {{% heading "synopsis" %}}


این دستور یک سرویس از نوع ExternalName با نام مشخص‌شده ایجاد می‌کند.

 سرویس ExternalName به‌جای اینکه فقط به پادها ارجاع دهد، به یک نشانی DNS خارجی ارجاع می‌دهد. با این کار، نویسندگان برنامه‌ها می‌توانند به سرویس‌هایی ارجاع دهند که بیرون از این پلتفرم، روی کلاسترهای دیگر یا به‌صورت محلی وجود دارند.

```
kubectl create service externalname NAME --external-name external.name [--dry-run=server|client|none]
```

## {{% heading "examples" %}}

```
  # Create a new ExternalName service named my-ns
  kubectl create service externalname my-ns --external-name bar.com
```
