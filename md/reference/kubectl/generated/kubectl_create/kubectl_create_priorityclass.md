## {{% heading "synopsis" %}}


این دستور یک کلاس اولویت با نام، مقدار (value)، وضعیت پیش‌فرض سراسری (globalDefault) و توضیحات (description) مشخص‌شده ایجاد می‌کند.

```
kubectl create priorityclass NAME --value=VALUE --global-default=BOOL [--dry-run=server|client|none]
```

## {{% heading "examples" %}}

```
  # Create a priority class named high-priority
  kubectl create priorityclass high-priority --value=1000 --description="high priority"
  
  # Create a priority class named default-priority that is considered as the global default priority
  kubectl create priorityclass default-priority --value=1000 --global-default=true --description="default priority"
  
  # Create a priority class named high-priority that cannot preempt pods with lower priority
  kubectl create priorityclass high-priority --value=1000 --description="high priority" --preemption-policy="Never"
```
