## {{% heading "synopsis" %}}


با این فرمان یک Secret از نوع مشخص‌شده ایجاد می‌شود.

 از Secret نوع docker-registry برای دسترسی به یک رجیستری کانتینر استفاده می‌شود.

 هر Secret از نوع generic نشان‌دهنده‌ی یک Secret از نوع Opaque است.

 هر Secret از نوع tls یک گواهی TLS و کلید مرتبط با آن را در خود نگه می‌دارد.

```
kubectl create secret (docker-registry | generic | tls)
```
