## {{% heading "synopsis" %}}


این دستور یک Secret از نوع TLS را از جفت‌کلید عمومی/خصوصی داده‌شده ایجاد می‌کند.

 جفت‌کلید عمومی/خصوصی باید از پیش وجود داشته باشد. گواهی کلید عمومی باید با قالب ‎.PEM کدگذاری شده باشد و با کلید خصوصی داده‌شده مطابقت داشته باشد.

```
kubectl create secret tls NAME --cert=path/to/cert/file --key=path/to/key/file [--dry-run=server|client|none]
```

## {{% heading "examples" %}}

```
  # Create a new TLS secret named tls-secret with the given key pair
  kubectl create secret tls tls-secret --cert=path/to/tls.crt --key=path/to/tls.key
```
