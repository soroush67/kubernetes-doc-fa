## {{% heading "synopsis" %}}


وضعیت rollout را نمایش می‌دهد.

 دستور 'rollout status' به‌طور پیش‌فرض وضعیت آخرین rollout را تا پایان آن دنبال می‌کند. اگر نمی‌خواهید منتظر پایان rollout بمانید، می‌توانید از --watch=false استفاده کنید. توجه کنید که اگر در این میان rollout جدیدی آغاز شود، دستور 'rollout status' دنبال‌کردن آخرین ویرایش (revision) را ادامه می‌دهد. اگر می‌خواهید روی ویرایش مشخصی ثابت بمانید و در صورت جایگزین‌شدن آن با ویرایشی دیگر، کار متوقف شود، از --revision=N استفاده کنید که در آن N ویرایشی است که می‌خواهید دنبال کنید.

```
kubectl rollout status (TYPE NAME | TYPE/NAME) [flags]
```

## {{% heading "examples" %}}

```
  # Watch the rollout status of a deployment
  kubectl rollout status deployment/nginx
```
