## {{% heading "synopsis" %}}


منبع مشخص‌شده را به حالت متوقف‌شده علامت‌گذاری می‌کند.

 کنترل‌کننده‌ها منابع متوقف‌شده را هماهنگ‌سازی (reconcile) نمی‌کنند. برای ازسرگیری یک منبع متوقف‌شده، از دستور "kubectl rollout resume" استفاده کنید. در حال حاضر فقط Deploymentها از توقف پشتیبانی می‌کنند.

```
kubectl rollout pause RESOURCE
```

## {{% heading "examples" %}}

```
  # Mark the nginx deployment as paused
  # Any current state of the deployment will continue its function; new updates
  # to the deployment will not have an effect as long as the deployment is paused
  kubectl rollout pause deployment/nginx
```
