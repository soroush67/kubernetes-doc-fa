    یک کلاستر دو ماشینی با یک نود control plane
    (که کلاستر را کنترل می‌کند) و یک نود کارگر
    (که بارهای کاری شما، مانند Podها و Deploymentها، روی آن اجرا می‌شوند) ایجاد کنید.

    ┌──────────────────────────────────────────────────────────┐
    │ On the first machine:                                    │
    ├──────────────────────────────────────────────────────────┤
    │ control-plane# kubeadm init                              │
    └──────────────────────────────────────────────────────────┘

    ┌──────────────────────────────────────────────────────────┐
    │ On the second machine:                                   │
    ├──────────────────────────────────────────────────────────┤
    │ worker# kubeadm join &lt;arguments-returned-from-init&gt;      │
    └──────────────────────────────────────────────────────────┘

    سپس می‌توانید مرحلهٔ دوم را روی هر تعداد ماشین دیگری که می‌خواهید تکرار کنید.
