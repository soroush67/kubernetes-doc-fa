توکن‌های راه‌اندازی (bootstrap token) را که برای پیوستن یک نود به کلاستر به کار می‌روند، تولید می‌کند.

### خلاصه

توکن‌های راه‌اندازی برای برقراری اعتماد دوطرفه میان نودی که به کلاستر می‌پیوندد و یک نود control plane به کار می‌روند.

این دستور همهٔ پیکربندی‌های لازم برای کارکردن توکن‌های راه‌اندازی را انجام می‌دهد و سپس یک توکن اولیه ایجاد می‌کند.

```
kubeadm init phase bootstrap-token [flags]
```

### نمونه‌ها

```
  # Make all the bootstrap token configurations and create an initial token, functionally
  # equivalent to what generated by kubeadm init.
  kubeadm init phase bootstrap-token
```
