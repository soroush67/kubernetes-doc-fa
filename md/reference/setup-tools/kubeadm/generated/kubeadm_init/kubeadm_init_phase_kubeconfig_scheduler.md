ایجاد فایل kubeconfig برای استفادهٔ زمان‌بند

### خلاصه


فایل kubeconfig مورد نیاز زمان‌بند را ایجاد می‌کند و آن را در فایل scheduler.conf ذخیره می‌کند.

```
kubeadm init phase kubeconfig scheduler [flags]
```
