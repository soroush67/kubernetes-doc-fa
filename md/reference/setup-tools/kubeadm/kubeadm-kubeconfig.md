دستور `kubeadm kubeconfig` ابزارهایی برای مدیریت فایل‌های kubeconfig فراهم می‌کند.

برای مشاهدهٔ نمونه‌هایی از نحوهٔ استفاده از `kubeadm kubeconfig user`، به
[ایجاد فایل‌های kubeconfig برای کاربران اضافی](/docs/tasks/administer-cluster/kubeadm/kubeadm-certs#kubeconfig-additional-users) مراجعه کنید.
